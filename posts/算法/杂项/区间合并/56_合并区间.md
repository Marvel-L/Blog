# 56. 合并区间

题目链接 : https://leetcode.cn/problems/merge-intervals/description/?envType=study-plan-v2&envId=top-100-liked

以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [starti, endi] 。请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。

## 难点

1. 移动左区间的时候需要考虑对应的条件
2. Golang 中排序的用法

## 思路

1. 将 ==数组按照左区间进行排序== 

2. 根据左区间进行枚举，判断 ==当前区间的左区间是否 <= 上一个区间的右区间== 

3. 如果小于则合并区间，合并区间就是一个 累加的过程

## Code 

```go
func merge(intervals [][]int) [][]int {
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][0] < intervals[j][0]
    })
    if len(intervals) <= 1 {
        return intervals
    }

    res := make([][]int , 0 )

    lft := 0 
    for i := 1; i < len(intervals) ;{ 
        for i < len(intervals) && intervals[i][0] <= intervals[lft][1] { // 左区间和右区间交合
            intervals[lft][1] =  max(intervals[lft][1] , intervals[i][1])
            i ++ 
        }
        temp := []int{intervals[lft][0], intervals[lft][1]}
        res = append(res, temp)
        lft = i 
    }
    return res 
}
```
