# 763. 划分字母区间

题目链接 : https://leetcode.cn/problems/partition-labels/?envType=study-plan-v2&envId=top-100-liked

给定一个只包含小写英文字母的字符串 s，将它划分为尽可能多的片段。同一个字母最多只能出现在一个片段中，按顺序返回每个片段的长度。

例如：

```text
输入：s = "ababcbacadefegdehijhklij"
划分："ababcbaca" | "defegde" | "hijhklij"
输出：[9, 7, 8]
```

## 难点

1. 将 ==同一个字母不能跨片段出现== 转换为一个区间约束。
2. 每个字母的区间都必须正确初始化，只出现一次的字母也有有效的右端点。
3. 区间合并时，==先结算旧区间，再移动 lft==，循环结束后还要结算最后一个区间。
4. 本题返回的是 ==片段长度==，不是合并后的区间，也不是区间的右端点。

## 思路

这次想到的是：维护 26 个字母的区间，然后进行区间合并。==这个思路是对的，答案对不上主要是实现细节的问题。==

可以复用 [56. 合并区间](../../杂项/区间合并/56_合并区间.md) 中的思路：按左端点排序，判断当前区间的左端点是否小于等于上一段的右端点，重叠就扩展右端点。

### 1. 每个字母维护一个出现区间

对于某个字母，记录：

```text
[第一次出现的位置, 最后一次出现的位置]
```

同一个字母不能分到不同片段，所以 ==从它第一次出现到最后一次出现，中间不能切开==。

例如 s = "abac"：

```text
下标：0 1 2 3
字母：a b a c

a 的区间：[0, 2]
b 的区间：[1, 1]
c 的区间：[3, 3]
```

a 的两次出现必须在同一段里，因此中间的 b 也只能和 a 放在同一段。

### 2. 按左端点排序，合并重叠区间

1. 将 ==字母区间按照左端点排序==。
2. 用 lft 指向当前正在合并的区间。
3. 如果 `cp[i][0] <= cp[lft][1]`，说明区间重叠，更新右端点：

   ```go
   cp[lft][1] = max(cp[lft][1], cp[i][1])
   ```

4. 如果不重叠，说明旧区间已经可以独立成为一个片段，先收集长度，再让 `lft = i`，开始处理新区间。
5. 循环结束，补收集最后一个区间。

对于 "abac"，合并过程是：

```text
[0, 2] + [1, 1] → [0, 2]
[3, 3] 不重叠   → 结算 [0, 2]，开始新区间 [3, 3]
循环结束        → 结算 [3, 3]

片段长度：[2 - 0 + 1, 3 - 3 + 1] = [3, 1]
```

注意：==重叠区间必须合并，相邻但不重叠的区间不需要合并==。例如 `[0, 2]` 和 `[3, 3]` 可以分成两段，合并它们反而会减少片段数量。

### 3. 为什么这样能得到尽可能多的片段？

每个字母的出现区间都不能切开，重叠区间也就必须放在同一段里；而两个合并后的区间之间没有字母跨越边界，可以安全切开。

因此，==该合并的必须合并，能切开的就立即切开==，得到的片段数量就是最多的。这也对应本题的贪心思想：当前片段不再有字母延伸到后面时，立即结束这一段。

## 本次代码的问题

### 1. 只出现一次的字母，右端点没有更新

原写法：

```go
if cp[tv][0] == -1 {
    cp[tv][0] = i
} else {
    cp[tv][1] = i
}
```

右端点只有在第二次及以后出现时才会更新。比如 "abac" 中的 b、c，分别会被记录成 `[1, -1]`、`[3, -1]`，而不是 `[1, 1]`、`[3, 3]`。

修改为：

```go
if cp[tv][0] == -1 {
    cp[tv][0] = i
}
cp[tv][1] = i // 每次出现都更新右端点，包括第一次
```

==第一次出现设置左端点，每次出现都设置右端点。==

### 2. 遍历从 1 开始，可能漏掉第一个有效区间

原写法：

```go
for i := 1; i < 26; i++ {
```

未出现的字母左端点是 -1，排序后会排在前面，因此很多输入下这个问题会被掩盖。

但如果 26 个字母都出现了，比如 "abcdefghijklmnopqrstuvwxyz"，排序后的下标 0 就是有效区间，直接从 1 开始会漏掉它。

修改为从 0 开始，仍然跳过左端点为 -1 的区间：

```go
for i := 0; i < 26; i++ {
    if cp[i][0] == -1 {
        continue
    }
    // ...
}
```

### 3. 遇到不重叠区间，先移动了 lft

原写法：

```go
lft = i
sp = append(sp, cp[lft][1])
```

这里已经将 lft 指向了新区间，收集到的就不是刚刚合并完的旧区间。

以 "abac" 为例，遇到 c 的区间 `[3, 3]` 时，应该先结算旧区间 `[0, 2]`，再开始处理 c。

正确顺序：

```go
sp = append(sp, cp[lft][1]-cp[lft][0]+1)
lft = i
```

==发现新区间，结算旧区间；结算完成后，再移动 lft。==

### 4. 收集的是右端点，不是片段长度

原写法：

```go
sp = append(sp, cp[lft][1])
```

本题要求返回片段长度，而下标构成的是闭区间：

```go
长度 = 右端点 - 左端点 + 1
```

例如 `[9, 15]` 的长度是 7，不是 15；单个字母的 `[3, 3]` 长度是 1。

### 5. 循环结束后，没有收集最后一个区间

只有在遇到下一个不重叠区间时，才会触发旧区间的结算。==最后一个区间后面没有新区间，必须在循环外补一次结算。==

例如 "ababa"，所有字母区间最终合并为 `[0, 4]`，中途没有出现不重叠区间；如果循环结束后不补收集，返回的就是空切片，而不是 `[5]`。

```go
if lft != -1 {
    sp = append(sp, cp[lft][1]-cp[lft][0]+1)
}
```

## Code

保留这次的区间合并思路，只修正上述边界和答案收集问题。

```go
import "sort"

func partitionLabels(s string) []int {
    cp := make([][]int, 26)
    for i := 0; i < 26; i++ {
        cp[i] = []int{-1, -1}
    }

    for i, v := range s {
        tv := v - 'a'
        if cp[tv][0] == -1 {
            cp[tv][0] = i
        }
        cp[tv][1] = i // 每次出现都更新右端点
    }

    sort.Slice(cp, func(i, j int) bool {
        return cp[i][0] < cp[j][0]
    })

    sp := make([]int, 0)
    lft := -1

    for i := 0; i < 26; i++ {
        if cp[i][0] == -1 {
            continue
        }

        if lft == -1 {
            lft = i
            continue
        }

        if cp[lft][1] >= cp[i][0] {
            // 重叠：扩展当前合并区间的右端点
            cp[lft][1] = max(cp[lft][1], cp[i][1])
        } else {
            // 不重叠：先收集旧区间的长度，再开始新区间
            sp = append(sp, cp[lft][1]-cp[lft][0]+1)
            lft = i
        }
    }

    // 收集最后一个合并区间
    if lft != -1 {
        sp = append(sp, cp[lft][1]-cp[lft][0]+1)
    }

    return sp
}
```

说明：这里使用 Go 1.21 及以上版本的内置 `max`。题目限定输入是小写英文字母，因此 `range` 返回的字节下标与字符位置一致。

### 复杂度

- 时间复杂度：扫描字符串为 O(n)，排序 26 个字母区间为 O(26 log 26)，合并为 O(26)。字母表大小固定，整体为 ==O(n)==。
- 空间复杂度：除返回结果外，只维护 26 个字母的区间，整体为 ==O(1)==。

## 边界自查

- `"a"` → `[1]`：只出现一次的字母也必须有右端点，并收集最后一段。
- `"abc"` → `[1, 1, 1]`：相邻但不重叠的区间可以分开。
- `"abac"` → `[3, 1]`：重叠区间合并，遇到新区间先结算旧区间。
- `"ababa"` → `[5]`：所有区间合为一段，循环外补结算。
- `"eccbbbbdec"` → `[10]`：嵌套区间不能缩短当前右端点。
- `"abcdefghijklmnopqrstuvwxyz"` → 26 个 1：所有字母都出现时，不能跳过排序后的下标 0。
- `"ababcbacadefegdehijhklij"` → `[9, 7, 8]`：多个合并区间按顺序返回长度。

## 总结

==建立正确区间 → 按左端点排序 → 重叠就扩展 → 不重叠就结算旧区间 → 最后补结算。==

和 56. 合并区间相比，本题主要多了“将字符串转换为字母区间”这一步，结果收集也从返回区间改成了返回区间长度。思路可以复用，但初始化、lft 的移动顺序和最后一次结算不能漏。
