我好像死了，今天我到底干了什么 我到底干了什么

因为今天是试用期的第二个月，任务比较少，我的开发任务已经做的差不多了 。 如果是前面那家公司 我估计自己就去要活做了

但是这家公司我不想，所以我今天其实是很空闲的

## 早上

早上我记得，我一直在干自己的事

9:00 - 9:30 去公司的路上，记单词 背八股文

9:30 - 10:00 复习了 LeetCode 的 4 个算法题

10:00 - 11:00 我记得这个时间我在整理 我上家公司项目中的 《资产管理 & 接入方式》很简单的一个东西好像是，我不知道为什么会整理了一个小时

但是确实就是整理了一个小时

11:00 - 11:40 我鬼使神差的 去看了 Agent 的项目教程，不过只停留在看，还没具体实践，但是就是看了 40分钟

然后吃饭，吃饭回来 12:09 左右 。吃完饭回来 继续看了 4个 LeetCode 算法题

然后刷了会抖音 睡觉

## 下午

下午 13.00 起来， 又刷了 2个算法题 。 不过这两个比较难，可以说是对着抄了一下

莫名其妙就到了 14:00 我记得我中间还做了一些事

然后开会开了半小时

我记得我下午

1. 排查了一个 log AI 排查到
2. 优化了一下简历 定稿了 2 个部分
3. 然后让 Ai 整理了一下 《延迟抓取》 和 《Websocket》 这两个部分的内容，看了一会没看懂
4. 自己去看了一下《Websocket》 的内容 没看懂
5. 又去搜索了一下 并发编程的 内容，没看完没耐心看了
6. 期间我记得我还 Re 了一下 之前一场面试的内容，简单总结了两个问题（其实这两个问题之前就总结过）

然后就到了 16.30，有点破防了，我确实是干了，但是我自己都不知道我干了什么，好像什么都没学到

我也不知道要怎么办

## 我现在的心里

1. 失败 不自信: 这应该是最近几个月最空的几天了，但是就算最空 我其实也没有很好的利用，更别提以后还要边上班边学

2. 愧疚 没有成就感: 其他同事都在上班，但是我一整天都没有上班，而且还有一种做贼心虚的感觉，谴责感很重

我死了

# 解决方案

1. 更好的管理 Agents 。 Agents 通过 日期 + 描述 的 方式命名。 并且尝试每天定期维护一个 Study Agent 到本地

   - 以 HTML 的记录 分类记录当前 Agent 的内容
   - 完整的记录 Agent 的对话
   - 形成 Agent 摘要 和 总结

主要目的 用于快速找到做了什么事，以及内容总结。

   - 因为很多问题 现在都会去问 Agent，问完 Agent 之后，我又会去看其他问题
   - 导致我看完其他问题之后，再来看当前Agent 的回答，我看不懂的时候 我就没耐心，然后就会废弃掉当前的 Agents

2. 明确每天最小原子 Todo

这个的前提其实是知道自己要干什么，有一个明确的 road ，但是我目前却没有导致比较困难。不过我大的方向确实有，例如我要学 Mysql 和 Redis 学完之后还需要学 Mysql 结合 Redis 还需要学习 分布式 的内容
