# 0.7.1 文章回看 V2

日期：2026-11-07。状态：本地实现，未发布；运行时 package 版本保持不变。

增加独立的 cloud 文章回看页面，登录后从账号面板进入。分类仅有想看、已看、暂不看，主动记录后归入已看，手动分类不增加次数；支持次数排序、筛选、已读撤销与个人历史。页面沿用原文章列表的封面和详情入口，无可见介绍标题、整页底色外框或定期回看模块；阅读操作直接跟随每篇文章。

新增 `013_article_reading.sql` 与账号私有阅读 API。快照 version 2 移除计划字段，兼容旧记录并保留次数、历史与 revision。持久化、会话授权、精确 Origin、幂等回执和冲突保护经过隔离 PostgreSQL 验证。Pages/cloud 构建、类型检查和 49 项针对性测试通过；真实浏览器验证三类交互、刷新、撤销及 1440/390/320px 明暗主题。全仓 lint 和全量回归问题详见[功能文档](../features/article-reading.md)。

## 本地登录修复

本地 `localhost:3013` 曾被只配置 `127.0.0.1:3013` 的后端拒绝，并与限流共用错误提示。HTTP 本地开发现接受相同配置端口上的两个精确地址；HTTPS、其他端口和域名限制保持有效。来源不符与 IP 限流分别使用 `origin_mismatch` / `rate_limited`。

后端已在原临时数据库上重启，真实浏览器通过 `localhost:3013` 完成密码登录并进入 V2。26 项账号/V2 前端测试、根类型检查和全部真实 PostgreSQL 后端测试通过；错误端口实际仍返回 403。
