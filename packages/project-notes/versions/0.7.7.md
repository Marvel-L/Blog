# 0.7.7 — 忏悔手绘动漫2.5D重做

## 用户选择与范围

用户否定0.7.6的3D外观，明确改为2.5D，并通过结构化询问选择“手绘动漫风（推荐）”。本版本直接修改原D-blog仓库，不另建原型。原导航、匿名观赏、登录交互和每账号私密归档接口保持；不推送、不上线。

## 表现与素材

- 使用八份手绘源素材：墓地地形石路、教堂无人深景，以及教堂外观、墓碑、枯树、乌鸦、长椅、门扇六份独立物件。
- 六份物件经真实背景移除，Alpha覆盖0–255，并查看深浅底检查图；长椅地面阴影移除。裁透明留边、等比压缩后以本地WebP加载；不引用临时24小时URL。源图及透明派生均在原素材画布保留可追溯关系。
- 墓地按远/中/近物件层和三层雾交错组景。雾浓度可调、慢速呼吸，镜头轻微视差；这是2.5D分层雾，不宣称三维视线积分体积雾。
- 墓碑以独立图片素材实例化，准确分类名是原生文字，不再绘制CSS石碑外形。每片最多6座，100分类可分页和目录定位，避免无限堆叠。
- 单扇门素材按本来宽高比例显示，左铰链从半开继续开启；门口白光增强并轻推镜头，约1.35秒后进入教堂。减少动态效果模式直接切换，暂停、弹层和页面隐藏时计时停止并恢复。
- 教堂深景、三排独立长椅、低密度雾、中央白光与透明凛分别组装。凛复用既有真实Alpha立绘，裁留边但不重绘身份，只有微呼吸；不使用旧黑底视频，不新增Cubism/骨骼模型。
- 点击凛显示“你今天想忏什么”的原生气泡，再点击打开私密记事表单。未登录提示请登录，后台存储/账户隔离不变。
