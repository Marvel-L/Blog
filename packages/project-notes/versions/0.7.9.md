# 0.7.9 — 忏悔近景倾诉与私密阅读

## 本轮范围

继续原 D-blog 手绘斜俯视 2.5D 工程，不新建原型。用户已确认“沉浸式倾诉与记事”，使用预设引导语，不接 AI 连续聊天、不外发记事给 AI 服务。本轮不生成视频，不声称新增 Live2D/Cubism。

## 实现

- 点击教堂内凛进入全屏人物近景、专属引导与对话框。先写话并点击“对凛说”，内容仍仅在内存；随后选择墓碑并“确认归档”才调用原私密保存接口。失败保持草稿，复用原幂等 ID/时间与冲突语义；账号变化卸载近景和草稿。
- 墓碑列表每则记事增加独立链接 `/confession/entry/:id`，支持直接打开/刷新并按当前真实会话读取。正文只属于本人，未登录提示登录；记录缺失/不属于当前账号统一反馈。详情使用独立阅读布局、日期与返回链接，不把私密内容放入 meta、OG、JSON-LD、SSG 或分享数据，纯文本安全渲染。
- 移除雾浓度滑块。远/中/近三层各三片不同相位/速度的流动雾，浓度自动随机并缓慢过渡，不改变动画速度/相位造成跳动。暂停/隐藏/弹层/减少动态效果保护保留。
- 路径沿线增加一份独立手绘植物簇，多地面锚点分布；教堂增加低叶丛与中轴铺面。提亮教堂/墓碑/柱/椅暗部，保留石纹和黑暗背景，减少荒废感。仍用真实地面路径、模块化墙/柱/家具，不用整幅场景图片。
- 修复缺失镜头 CSS 变量导致整个缩放变换失效的问题；共同缩放适配完整场景，避免右侧教堂被裁切。
- 正视凛近景重新真实去底，清理头頂残留灰底。旧图保留，不重新生成或更改身份；植物/新Alpha派生回读归档。
