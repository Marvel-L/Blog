# 0.5.1 — Trend 刷新恢复同步

日期：2026-10-22。

用户在 GitHub Pages 完成 GitHub 同步后，刷新立即失去同步。根因为专用授权仅保存在组件内存，
新挂载只对 cloud 同源 Cookie 自动连接。

授权改为当前标签页 sessionStorage 保存 `{ token, expiresAt }`，按 API origin 隔离。
刷新与路由重新挂载会用 Bearer 请求 dashboard，由服务端确认身份后恢复账号草稿并继续同步。
服务端现有 1 小时有效期、来源绑定、会话关联和退出撤销保持不变，无 API 或数据库迁移。
token 不进入 localStorage、URL、日志或账号草稿。

恢复网络失败保留未过期授权，聚焦、online 与 15 秒轮询自动重试；401、本机到期、主动断开及账号退出清除记录。
卸载只取消请求，保留标签页授权；关闭标签页后需重新连接。
严格校验 exchange 返回的 token 与有效期，存储不可用如实提示；写入失败仍允许本次内存授权同步。
generation 与授权匹配守卫防止迟到 401 清除新授权、旧撤销失败覆盖新连接或退出后恢复旧身份。
