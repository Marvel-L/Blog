# 0.7.13 — Mind 节点呈现与拖动

日期：2026-11-16。代码与本地交互验证完成；未发布线上。

节点表情作为文字前缀同行显示；节点宽度按实际字体和最长一行伸展，仅手动换行时增加高度，各节点可以使用不同尺寸。编辑器同样关闭自动折行。

新增六种节点颜色、自定义颜色和恢复自动配色。可选 `color` 字段随节点 JSON 自动保存，服务端兼容旧节点并校验颜色格式。

拖动到目标上方或下方调整同级顺序，中央或后侧移动为目标的子主题。移动整个分支时保留子节点、文字、颜色、表情，支持撤销重做；禁止根节点移动、自身/后代循环及超过 32 层的移动。拖动提供放置提示，鼠标与手机触屏均可使用。

浏览器确认同行表情、不同尺寸、仅手动换行、颜色刷新恢复、上下排序、整条分支换父节点、撤销重做、循环保护与 390px 手机触屏拖动、深色主题。修正了聚焦画布自动滚动造成的连续拖动落点偏移。测试补充前端布局与移动、旧格式兼容、颜色保存以及真实 PostgreSQL 顺序/层级/手动换行持久化。

验证结果：24 项 Mind 前端测试通过，服务端 `TestMind` 真实 PostgreSQL 测试通过；全仓类型检查和 ESLint 通过（仅既有 8 项警告）；cloud 构建、SSG、SEO、隔离审计和后端二进制构建通过。完整前端/脚本回归 1532/1533 项通过，Love 清单的一项用例未通过，其文件随后独立复测 20 项全部通过。为适配 Node 26 下的浏览器存储替身，修正 Mind 与简历存储故障测试的 mock 目标，未改变简历运行逻辑。

完整 Go 后端 `-race` 与真实 PostgreSQL 隔离回归，各包全部通过。

发布需同步更新 cloud 前端和后端。详见 [Mind 说明](../features/mind.md)。
