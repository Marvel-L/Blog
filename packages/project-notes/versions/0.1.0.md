# 0.1.0 — 云端账号与双部署基础

日期：2026-10-20。状态：代码及本地验证完成，未上线服务器。

## 交付

- 引入 npm workspaces；根目录仍是博客，新增独立后端与工程记录 package。
- pages/cloud 两个目标共用原 SSG 构建与审计；Pages 显式裁剪账号代码和 API 引用。
- 云端账号栏：GitHub 登录入口、退出、本次访问记录开关、最近 20 条个人记录。
- Fastify API：一次性 OAuth state + S256 PKCE、7 天数据库会话、Origin 校验、请求限流、脱敏错误、no-store。
- PostgreSQL：用户、授权事务、会话、事件；事务迁移、事件幂等、过期记录清理。
- Docker Compose：数据库、一次性迁移、API、Nginx、自动 HTTPS 的 Caddy；数据卷与镜像标签独立管理。
- CI 检查后端类型/测试并构建两种站点制品；保留现有 Pages 发布，不自动部署服务器。
- 新增 ai-rules/cloud-platform.md，以及部署、本地联调、备份和恢复手册。
