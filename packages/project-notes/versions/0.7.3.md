# 0.7.3 草稿测试与原型 lint 修复

日期：2026-11-07。状态：本地维护，未发布；没有更改运行时 package 版本。

Anki 草稿保存失败测试现在直接模拟实际使用的 `localStorage` 写入失败，兼容 jsdom Storage 和 Map 替身。原有失败断言保留，增加实际写入、错误提示和无成功回调检查；生产逻辑不变。

ESLint 按文件用途检查原型：文章原型的两个生成 bundle 和第三方 Mermaid 分发库不检查，手写原型脚本使用浏览器 globals，构建脚本仍使用 Node globals。Planner 原型移除重复的浏览器全局声明。新增三个测试保护检查范围和未定义名称检测。

覆盖率首轮在发布上传测试复现 3 项默认 5 秒超时。这组测试实际执行 tar、SHA256 校验、多批次子进程传输及 18 MiB 随机载荷处理；修后全仓运行单个用例实际耗时最高约 9 秒，原 5 秒预算不足。现仅为该套件设置 30 秒时间预算；全部 6 项内容一致性、乱序重组、分块失败、损坏拒绝和临时文件清理验证保留。发布脚本和全局测试参数没有修改。

验证通过：9 项 Anki 草稿测试、3 项 lint 配置测试、6 项上传集成测试、根类型检查和最后版本完整 `npm test`（167 文件、1381 项前端/脚本测试，以及真实隔离 PostgreSQL 后端测试）。全仓 `npm run lint` 为 0 errors，保留 8 条原有 Fast Refresh warnings。

完整 `npm run test:coverage` 通过，同样执行全部 1381 项测试及真实 PostgreSQL 后端测试。覆盖率为 statements 68.55%、branches 64.46%、functions 70.79%、lines 69.74%，全部超过仓库门槛。
