# 0.7.0 Planner 工作台

日期：2026-11-07。状态：本地实现，尚未发布；没有创建版本标签或变更运行时 package 版本。

## 行为

- 按确认后的 Planner demo 重做月度目标和每日遗留工作台，兼容博客明暗主题；窄屏切换两类任务并自动定位当前月份。
- 月度目标增加编辑、分类、优先级、搜索、排序和删除撤销，保留真实月/季度/年度进度及 Markdown 导出。
- 云端同步改为浮球，合并月度和每日任务的实际上传状态、最近确认、失败、冲突和 GitHub 回写状态。
- 登录并连接的账号可以记录自己的每日遗留、说明和来源日期，安排今天/明天，完成后按日期回看；未完成任务跨日保留。
- 账号数据与匿名计划隔离；静态页面刷新保留本机编辑，读取模板、退出账号和没有内容变化时不会回写项目 Markdown。

## 数据与迁移

月度版本 1 保持兼容，新增可选分类与优先级元数据，前后端 Markdown 格式一致。每日任务使用独立的私有快照和 `GET/PUT /api/v1/planner/daily`，不进入公开 Markdown 或 GitHub 队列。

新增 `012_planner_daily.sql`，需要随后端发布执行。沿用服务器会话、GitHub 绑定守卫、精确 Origin 白名单和 CAS revision / mutation ID 协议；并发写入、重复请求和冲突处理经过真实 PostgreSQL 测试。
