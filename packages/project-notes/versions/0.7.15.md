# 0.7.15 — Mind 页面全屏与稳定输入

日期：2026-11-17。代码与本地浏览器验证完成；未发布线上。

全屏统一为占满浏览器页面的内容区，保留地址栏与标签页，移除系统 Fullscreen API 的调用和事件分支。继续共享同一编辑器实例，支持 Esc 退出、背景交互隔离、滚动恢复和画布视角保持。

修正节点逐字输入时的抖动：编辑开始时保存节点布局；输入期间固定编辑框左上角与周边节点，编辑框按内容扩展，完成编辑后统一排布。输入文字左对齐，字体尺寸在绘制前测量并缓存，清除旧宽度下遗留的光标滚动。保留手动换行、自动保存、撤销与按内容变化的节点尺寸。

浏览器逐帧采样：普通模式 132 帧、页面全屏 150 帧，输入框起点、周边节点的位置偏移和横向滚动均为 0，输入元素始终保持同一个 DOM。验证了中英文连续输入、手动换行、自动保存、刷新内容恢复，以及 390px 手机页面全屏；系统全屏 API 调用次数为 0。

29 项 Mind 测试通过；完整前端/脚本回归 194 个文件、1538 项全部通过。全仓类型检查、ESLint（仅既有 8 项警告）与 cloud 构建的 SSG、SEO、隔离审计均通过。

需发布更新后的 cloud 前端。详见 [Mind 说明](../features/mind.md)。
