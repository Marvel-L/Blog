# 0.1.3 — 数据库备份与恢复

日期：2026-10-21。功能包仍为 0.1.0；本次独立安装运维脚本，不改变当前站点 release。

## 交付

- 先同步 custom 的 857f7f6，核实今天的新内容与自动发布已经生产完成，未重复开发发布链路。
- 使用 age 公钥加密 PostgreSQL custom dump；密文包含快照清单，dump 与表行数使用同一个导出事务快照。
- 每日北京时间 03:00 后随机 15 分钟内自动备份，失败重试；保留 14 天，失败不清理已有备份、不发布半成品。
- 共享部署锁避免与迁移重叠，备份锁串行维护；脚本安装在 release 外，发布切换不影响维护路径。
- 恢复工具验证密文与 dump 摘要、归档成员和快照行数，恢复到随机临时库，校验约束后删除临时库。
- 私钥长期只保存在本机；服务器仅保留收件人公钥。首次演练通过隐藏输入临时放入 /run，结束后已删除。
- 首份加密副本已复制到 Mac 仓库外目录，完成 SHA256、解密和 dump 摘要验证。

## 余项与边界

- Mac 副本是一次手动异地复制，异地自动传输待确定存储位置；后续每份备份尚未做恢复演练。
- 完整服务器恢复仍需要独立保存的 OAuth/数据库/TLS 配置，本包不包含这些密钥。
- 第二真实账号生产隔离、应用发布短暂中断优化、生产回滚演练和下一版阅读进度云同步仍单独跟踪。
