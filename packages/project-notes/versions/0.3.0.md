# 0.3.0 — Go 后端

日期：2026-10-21。依据用户要求，将 packages/server 的 TypeScript/Fastify 实现替换为 Go。

## 范围

- net/http、pgxpool，按 config/github/httpapi/store 拆分；cmd/server 管理进程和优雅退出。
- 保留全部 7 个 API、JSON 字段、OAuth state/PKCE、Cookie、7 天会话、事件去重和 90 天保留策略。
- 用户更新、新会话、旧会话撤销与登录事件改为同一事务提交。
- 编号 SQL 内嵌到二进制，沿用原 001_initial.sql、schema_migrations 和事务锁 7102026。
- 旧 SHA-256 会话兼容，不修改用户、记录或数据库卷，不需要更新现有 OAuth App/Secret。
- npm 命令保留开发/CI 入口；删除旧 TypeScript 后端、Fastify/pg/PGlite/tsx 依赖。
- Docker 改为 Go 多阶段编译、scratch 运行镜像、CA 根证书、非 root UID，使用程序自身健康检查。
- CI 加入 Go 和隔离 PostgreSQL；保留 check/test/build 三 job，缺少 SQL 测试库直接失败。
- 云端发布包只带 Go 服务端、部署配置和前端 dist，不再需要根及前端 npm 依赖清单。
- 已更新架构 ADR-007、ai-rules、开发、测试、发布与旧版回滚说明。

## 验证

- Go race 检测及真实 PostgreSQL 17 网络集成测试通过，包括旧 Node 摘要 fixture、授权重放/过期、会话替换/注销、CSRF、账号隔离、并发去重、故障事务回滚、清理和并发迁移。
- Go internal 与 migrations 合计语句覆盖率 86.4%；前端与脚本 874 项测试及原覆盖率门槛通过。
- 前端 TypeScript、go vet、本地 Go 编译、ESLint 通过；ESLint 保留既有 4 条 Fast Refresh 警告。
- Pages/cloud 两种 SSG、SEO、产物隔离构建通过。
- 服务器成功构建 Go Linux 镜像（约 4.45 MB、UID 10001），隔离容器真实 HTTP 验证旧会话、事件持久化/去重、查询与注销；SIGTERM 优雅退出码 0。测试数据库及端口均与生产隔离。
- 实际发布包核验后修复 macOS tar 自动添加 AppleDouble 元数据的问题；归档文件与 SHA256SUMS 全量对应，不携带额外元数据。
- 当前终端 Node 25 超出根 package engines；曾触发前端测试 localStorage 错误，使用受支持 Node 24.19.0 重跑全部通过，没有修改前端测试来规避。

## 发布状态

代码和隔离验证完成，尚未推送或替换生产 API。线上仍为 857f7f6 的 Node 版。
本版不声称已完成真实 GitHub OAuth 生产验收；后续推送后通过现有 CI 和云端发布流程切换，使用浏览器验证登录、刷新、访问记录和退出。
回滚到 Node 必须使用旧 release 的 Compose 文件及镜像，数据库不需要回退。
COS 异地自动传输仍为待办，等待存储桶名、地域和安全凭据配置方式。
