## 三维空间与资产

- Three.js客户端懒加载；SSG仍为确定的公开说明与入口，不构造GPU实例。
- 八个独立GLB：三种墓碑、枯树、乌鸦、长椅、门扇、教堂。通过 `scripts/build-confession-assets.mjs` 离线生成，运行时加载和实例化；墓碑不再以CSS卡片绘制。
- 四张生成表面素材：风化石材、潮湿泥地、旧橡木、哥特彩窗；经过等比压缩供GLB材质使用，而非用作整幅场景背景。
- 第一人称WASD/方向键、拖动环视、触屏移动；墙体、树干、长椅、墓碑与边界碰撞。门扇从半开状态绕铰链打开，开门完成后方可穿过门口，进入同一世界的教堂内部。
- 世界坐标噪声高度雾、24步视线积分及不透明深度截断；密度可调、慢速呼吸。柱廊、长椅、彩窗、祭坛、中央聚光都有独立几何与灯光。
- 凛已真实去背景，保留黑衣、头纱；Alpha值覆盖0–255并完成浅色、深色落底检查。当前是三维空间中的透明动画画风角色平面，有微呼吸，不是全3D骨骼角色，也不把旧黑底MP4假称透明动作。
- 点击凛后气泡绑定头部投影并限制在可见屏内，再点击打开原私密记事表单；弹层打开暂停移动和场景交互。
- 三维加载或WebGL失败提供可见失败与重试，不静默退回旧背景图。
