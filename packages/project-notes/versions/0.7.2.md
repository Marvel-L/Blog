# 0.7.2 Trend 同步浮球

日期：2026-11-07。状态：本地实现并验证，尚未发布；未创建版本标签或修改运行时 package 版本。

## 行为

- 将 Trend 页面内的云端同步卡片改为 Planner 风格的玻璃悬浮球，展示实际待上传、请求中、成功、失败与冲突状态。
- 点击查看账号、最近确认时间和同步详情；保留立即同步、断开、取消授权与版本选择操作。
  默认关闭状态不占页面布局，详情支持焦点管理、关闭按钮、Esc 和外部点击。
- 删除页面顶部大小标题及“把日常选择，放在同一张图上。”文案，使用隐藏 H1。
- 下线 JSON 导入导出，移除按钮、文件选择、操作逻辑与工具栏，并清理 SEO 描述、错误和冲突提示中的相关建议。
- 云端同源复用统一账号登录面板，登录事件后由 Trend API 验证身份并加载；
  退出取消请求、恢复匿名配置。Pages/本地继续使用原 PKCE 弹窗授权和标签页恢复。
- 保留现有类别、条目、图表口径与持久化协议，不需要新增数据库迁移。
