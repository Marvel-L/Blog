# 0.7.10 — 忏悔体积雾与教堂内人物演出

## 首句修正

用户明确纠正首句为“你今天想忏悔什么？”。字幕同步修正。参考音色生成的首句有转写疑点、第二候选近乎静音，均未采用；最终采用独立原创成年女性普通话配音 `greeting-v4.wav`，已转写核对准确台词。旧首句保留，其余五句及场景不变；新文件重新写入真实 WAV 长度，避免生成源的流式头错误。首句文字增加精确断言。

## 本轮范围

继续原 D-blog 手绘斜俯视 2.5D 工程；不重新建应用，不切回低模 3D。用户已选择中文配音，维持预设引导与私密记事，不接 AI 连续聊天、不向外部服务发送用户输入。本轮不生成新人物视频。

## 实现

- 移除教堂全部四处植物，保留墓地沿路独立植物簇和原墙、柱、长椅、祭坛。
- 墓地改为原生 WebGL 体积雾：正交镜头中的三维噪声密度沿射线分 40 步积分透射与散射，低处浓、高处淡；风驱动空间流动，随机初相与慢周期浓度变化。以独立物件真实 Alpha 轮廓构建高度代理截断雾射线，**不是三维 mesh 深度缓冲**。屏幕边缘渐隐，冷青夜色与门光融合；WebGL 不可用时明确提示，不以 CSS 白雾冒充体积雾。
- 凛在中轴通道内连续移动到随机目标，停留后再走；按当前位置进行前后排序、脚下投影跟随。暂停、后台、弹层及减少动态效果时冻结，恢复不瞬移。当前是现成站姿精灵位移与小幅步行摆动，**不是新步行帧或骨骼模型**。
- 点击凛后不切页面或背景，在原教堂上显示近景透明立绘、底部 Galgame 宽框式对话布局、姓名、逐字对白、下一句、回听、静音与结束。人物呼吸/摇摆随实际播放状态切换为轻微说话摆动；没有口型、眨眼或 Cubism。输入时不会被“下一句”误切回前序台词，账号悬浮球不遮对白。
- 六句固定中文合成配音保存为工程本地 WAV，原创成年女性音色，不模仿原作声优。源音频已转写核对，修正“六个长静音段≠六句”的切片错位；WAV 头重建为真实长度。静音、下一句、退出停止旧音频，后台暂停、前台恢复未完成句子，播放或加载故障提供回听提示。
- “对凛说”仍只在内存预览；选择墓碑并确认归档才调用原接口。保存失败保留草稿/幂等身份，账号变化销毁私密视图。单则独立阅读、noindex 与通用 SEO 信息保持。

## 验证与边界

- 修复场景卸载后排队 ResizeObserver 回调访问空节点的问题，新增卸载回归；不改变场景共同尺度。
- 当前功能目录 10 文件、40 项定向回归通过，新增 5 项声音生命周期和 3 项随机走动/冻结测试；typecheck 与功能目录 eslint 通过。
- 当前完整前端与脚本 180 文件、1448 项通过，Pages/cloud 双构建及构建、SEO、部署隔离门禁通过。测试中的场景雾为组件 mock，不等于 GPU 渲染测试。
- 浏览器实际看见墓地雾、无草教堂和原背景 Galgame；前台 `hidden=false` 时人物位置已变化，点击人物后 `speaking=true`（由真实 audio playing 事件驱动），确认播放启动。保存行为通过组件回归，不向真实账号写测试内容。没有把播放启动称为听感验收；首句 ASR 将“忏”识别为“唱”，保留原固定台词并记录识别歧义。
- 原 Go 接口、迁移、生产数据库与原 3001 服务不变；28742 本地预览保留，未 push 或上线。视觉改善不等于用户审美已批准。
