# 0.7.8 — 忏悔斜俯视游戏空间

## 本轮授权与诊断

用户否定0.7.7背景拼贴、墓碑同朝向、长椅排列与人物比例；本轮结构化确认采用斜俯视游戏镜头。保留手绘动漫2.5D、原Blog仓库、匿名观赏/登录私密交互和原存储，不回到自由行走低模3D。

## 当前实现

- `sceneSpace.ts`统一地面坐标和正交投影，尺寸以同一世界比例确定，不按各自视口百分比独立缩放。`SceneGround.tsx`按投影建立地面、小路、房间墙体和低台；旧完整墓地/教堂背景不再运行。
- 地面与墙使用小块手绘表面材质，不是禁止所有材质纹理；背景环境色与照明单独实现。墙面彩窗按房间平面投影分段，不是一张预先构图好的室内图。
- 两种实际墓碑视角供路径两侧使用；碑名保留原生可交互文字。六座/页和100分类目录保持。
- 新长椅背面素材，左右两列三排、同一尺寸、共同朝祭坛。第一张未成功改视角的椅图已展示并拒绝使用，修正版保留来源。
- 独立手绘哥特柱、低祭坛、斜俯教堂外观和完整俯视凛均真实去背景；七个透明物件已查看深浅底检查图，所有运行文件本地WebP，不依赖临时链接。
- 凛保留蓝发紫眼/脸型/黑白高领长袖及踝修女服，按1.62米参考尺度落地在祭坛前；不是站桌上，也没有新Live2D/骨骼/动作视频。
- 物件按地面深度排序，雾在其中分区穿插。轻镜头移动作用于整体，避免物件滑过地面。气泡保持独立原生DOM，在展开时升到前层避免被椅背遮挡。
- 开门仍先铰链旋转再切场景，1.35秒；弹层/后台/暂停不继续计时。减少动态效果直接切换。
- 原服务端会话鉴权、每账号私密隔离与记事接口不变，不存localStorage、不入公开SSG或搜索。
