# 0.6.0 月度规划

## 范围

- 新增 `/planner` 月度规划界面：保留实时本地时钟，以及 Year / Month / Quarter 电池式日历进度。
- 以单一 `Monthly Task` 区域展示每月待办，支持按年份和月份查看、新增、完成、取消完成和删除。
- 支持打开、解析、保存和导出 Markdown；项目内固定源文件为 `planner-data/monthly-planner.md`，本地开发时页面改动自动原子写回；构建时直接输出为 `dist/planner-data/monthly-planner.md`，不经过 `public/`。
- Year / Month / Quarter Charge 均按相应周期内“已完成任务数 / 全部任务数”计算，无任务时为 0%。
- GitHub Pages、本地与云端复用同一页面和账号同步模型；本地草稿保存在浏览器，账号数据通过现有来源绑定授权同步到 PostgreSQL。
- 新增 `003_monthly_planner.sql`，使用 CAS revision、mutation id 和冲突选择防止覆盖。
- 云端保存后生成规范 Markdown，并进入后台 GitHub Contents API 提交队列；失败指数退避重试，不阻塞用户保存。

## 部署配置

GitHub 回写为可选能力。服务端设置以下变量后启用：

- `PLANNER_GITHUB_TOKEN`：仅授予目标仓库 Contents 读写权限的 fine-grained token。
- `PLANNER_GITHUB_OWNER` / `PLANNER_GITHUB_REPO`。
- `PLANNER_GITHUB_BRANCH`，默认建议 `custom`。
- `PLANNER_GITHUB_FILE`，固定为 `planner-data/monthly-planner.md`，与本地开发和 Pages 使用同一项目源文件。

未配置令牌时，云端同步仍可用，页面明确显示“未配置 GitHub 回写”。令牌不发送到前端、不写数据库、不进入日志。
