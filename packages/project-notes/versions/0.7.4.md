# 0.7.4 Love 必做清单

日期：2026-11-07。状态：本地功能完成，尚未发布；没有更改运行时 package 版本。

Love 面左侧导航新增「必做」，登录后记录想与女朋友一起完成的一生清单。打开后展示已保存内容，单独「添加」按钮打开弹窗。按“大事项 → 小任务”排列，支持备注、分组编辑、小任务独立完成和撤销、完成日期、删除确认、状态筛选与完成进度，适配手机和明暗主题。

展示区移除顶部标题、统计描述与进度条，清单改为磨砂透明玻璃；Love 全屏复用 Blog 的日间/深色天空，退出后恢复个人背景选择。多个大事项通过下拉选择器切换，每次展示一个，筛选只统计当前事项。新增确认后自动选中新事项，删除后回退到剩余事项。

云端同步独立为 Trend/Planner 风格的悬浮球，支持展开详情、手动刷新、保存重试、版本冲突和最近确认时间，避让账号球。

沿用真实账号会话，普通密码账号也可使用；云端清单按账号隔离。新增迁移 014 和 `/api/v1/love/tasks`，采用版本比较、事务与幂等回执。v2 分组兼容并无损转换旧 v1 平铺记录，不需要额外迁移。失败保留弹窗输入，多设备冲突需读取云端版本。账号面板从普通页面内容中移出，使 Love 面内可直接登录。

分组版本已完成类型检查、全仓 lint（0 错误）、82 项模型/UI/导航/App 集成测试、真实 PostgreSQL（含 race）和 1440/390/320px 六种浏览器布局与实际操作验证。相关逻辑、账号挂载、真实 SQL 和故障分支均有测试；验证细节及上线要求见 [Love 必做清单](../features/love-tasks.md)。

分组版本完整 `npm test` 通过：170 个前端/脚本测试文件、1398 项测试和全部后端测试。Pages/cloud 构建、SSG、SEO 与部署隔离审计通过。透明清单和同步球调整后，类型检查、相关 lint 和 99 项相关测试通过。

透明清单/同步球版本双目标构建审计与六种 Chrome 布局/操作验证通过，包含透明背景、浮球避让、刷新失败恢复和手机保存流程。

天空磨砂/大事项选择器版本类型检查、相关 lint 和 105 项相关测试通过，覆盖每次展示一个事项、筛选范围、其他事项保留、增删自动选择、刷新保留选择、重试后选中新增事项及背景切换恢复。
