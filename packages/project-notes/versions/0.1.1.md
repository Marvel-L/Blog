# 0.1.1 — IP HTTPS 部署修订

日期：2026-10-20。功能包仍为 0.1.0。本修订交付无域名部署支持；公网博客已运行，账号 API 待 Secret 和真实 OAuth 验收。

## 变更

- IP 专用 Caddy/Compose 配置，使用公开可信证书与 HTTP-01 webroot。
- Certbot systemd 定时续期与证书重载；摘要只在重载成功后更新。
- Nginx 按请求解析 API 服务，允许账号尚未配置时独立提供博客。
- API 缺少真实凭据时继续拒绝启动；增加填好凭据后的启动脚本。
- 后端 Docker 构建只安装自身 workspace，显式声明 TypeScript 构建依赖。
- Caddy 运行时错误日志删除请求 URI 和认证头，保护 OAuth 回调信息。

- 本轮类型检查、全仓 ESLint、后端 23 项测试、Pages 完整构建通过；cloud 完整构建及隔离审计已通过。
