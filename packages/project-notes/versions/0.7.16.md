# 0.7.16 — Mind 大导图排布与输入性能

日期：2026-11-17。代码与本地验证完成；未发布线上。

修正节点数量多时，新增主题和文字增长引发大范围位移、页面卡顿的问题。各分支改为从固定顶部展开，父子间距由父节点自身宽度决定，取消全图居中与同层最大宽度耦合。在最后一个主题后追加节点时，原有节点位置保持不变；中间分支增加高度时，仅顺延需要腾出空间的后序分支。不同尺寸的节点仍避免重叠；输入期间继续固定编辑框起点与其他节点。

未变化的节点、连线复用布局对象，独立组件跳过重复渲染；画布仅渲染视野及周围缓冲区域，平移/缩放后显示对应节点，正在编辑的输入框保持挂载。完整树仍用于布局、导航、拖动和保存。创建主题时共用一次布局结果，避免重复计算编辑和视角定位。

字体测量复用一个隐藏元素并在卸载时清理，按节点缓存尺寸、按文本行缓存宽度；只测量变化的文字，尺寸未变化时不再发布新尺寸。主题/字体切换使缓存失效，维持实际字体宽度和手动换行。

本机 Chromium 开发模式、1440×960，使用真实本地账号和 PostgreSQL，针对最后一个主题后追加同级再连续输入长文本的样例：

| 节点数 | 输入到下一帧中位耗时（之前 → 之后） | P95（之前 → 之后） | 新增时旧节点位移数（之前 → 之后） | 编辑完成时旧节点位移数（之前 → 之后） |
| ------ | ----------------------------------- | ------------------ | --------------------------------- | ------------------------------------- |
| 500    | 51.8ms → 10.4ms                     | 114.9ms → 16.8ms   | 498 → 0                           | 80 → 0                                |
| 990    | 96.9ms → 11.1ms                     | 195.8ms → 17.8ms   | 988 → 0                           | 160 → 0                               |

优化后的两个样例在输入期间没有 50ms 以上的主线程长任务。当前视野各渲染 8 个节点，所有旧节点的完整布局世界坐标均保持不变；云端保存包含全部 501/991 个节点，刷新恢复通过。结果仅针对上述本机与样例，不代表所有设备或分支结构。

36 项 Mind 回归覆盖末尾追加、局部宽高变化、节点无重叠、布局引用复用、视野外编辑器保留、跨视野连接线、字体缓存与失效、平移恢复远处节点及原有同步行为。全量前端/脚本回归 195 个文件、1545 项通过；类型检查、ESLint（仅既有 8 项警告）和 cloud 构建的 SSG、SEO、隔离审计通过。全量脚本测试使用 Python 3.13，避免系统旧版 Python 不支持 tarfile 的 filter 参数。

真实浏览器验证普通/页面全屏输入起点与周边位置偏移均为 0，输入框 DOM 不变；拖动同级和整条分支、撤销重做、防后代循环、颜色/手动换行保存、刷新恢复、390px 手机触屏和深色主题均通过。

发布仅需更新 cloud 前端，本次未变更数据结构或后端接口。详见 [Mind 说明](../features/mind.md)。
