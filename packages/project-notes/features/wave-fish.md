# 水波与鱼跃互动

日期：2026-10-23。

首页上下分割线与页脚共用 `WaveFishDivider`。水面升级为三个连续循环、速度与相位不同的 SVG 波层，
叠加轻微上下呼吸；鱼的横向行进与上下弧线分层，尾鳍轻摆，起跳和落水位置各有水滴与双圈涟漪。
自动鱼跃交替位置、方向、高度和间隔，保持克制节奏。

鼠标掠过水面显示局部微光和涟漪，点击或轻触可在对应位置引出鱼跃；
原生按钮支持 Enter/空格，键盘触发从中央开始。手机保留纵向滚动手势，效果不拦截其他页面区域。
密集交互最多保留三次效果，动画结束后移除节点；指针位置由 rAF 写 CSS，不重渲染整页。
离开视口或隐藏标签页暂停 CSS 动画和自动鱼跃，卸载清理观察器、监听器与定时器。
减少动效模式只保留静态水面，点击显示静态涟漪。

渐变使用组件独立的 useId，避免同页多条水面引用冲突；SSR 首帧没有临时鱼跃节点，不读取客户端位置或随机值。
样式从全站入口加载 `styles/waveFish.css`，删除原有水波和鱼跃规则。无新增依赖。
