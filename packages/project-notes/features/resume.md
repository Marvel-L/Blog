# 私有定稿（原简历）

代码与本地验证完成；生产部署和线上账号数据尚待验证。

## 使用方式

- 导航「定稿」进入 `/resume`。生产沿用 `/Blog/resume`；Pages 导航跳到云端同源入口，仅 cloud 构建包含编辑器和账号 API。
- 每个账号按名称管理多份定稿，不设置分类；读取与编辑均要求登录，默认仅本人可见。支持创建、可选面试提纲、搜索、切换、复制、改名和删除；新建默认空白。最多 50 份、单篇 10 万字、总正文 100 万字、集合快照约 8 MB。复用账号密码与 GitHub 登录。
- 原有单份简历无损转换为「我的简历」，正文和评论定位不改写；只读打开不自动保存升级。定稿使用 `?document=<UUID>` 定位，支持复制链接，仍须本人登录。
- 「导入」读取 `.md`、`.markdown`、`.txt` 和 `.json` 备份；也可在「Markdown」模式直接粘贴全文。Markdown 文件上限 1 MB，JSON 备份上限 8 MB。单篇导入替换当前正文及评论，已有内容时先确认；集合备份导入新增文档副本，保留原有内容。
- 「文档编辑」可直接修改正文、标题和列表，支持加粗、斜体、下划线、撤销、重做；代码块支持选中文字后使用现有高亮、标红、标绿、清除颜色操作。「预览」只读。
- 选中文字后右键提供添加评论、高亮、标红、标绿、清除颜色。键盘可用 Shift+F10 打开菜单；手机使用换行工具栏。
- 评论在桌面右侧展示，900px 以下移到正文下方；包含引用、内容、时间，支持编辑与删除。点击引用定位原文，点击正文批注标记激活评论；同一处多条批注可循环激活。
- 评论随正文保存、按账号隔离。正文选区通过持久化标记定位，支持重叠选区、跨段落和表格；前方插字不会错位，相同文字不会误定位。原文被删除或 Markdown 定位标记被移除后，评论保留并提示，不自动猜测关联。
- 每份简历最多 100 条评论，单条 2000 字，选中引用最多 1000 字；代码块和代码文字暂不支持批注。写评论期间正文更改时拒绝使用旧选区，保留未提交输入并提示重新选择。
- Markdown 是唯一正文来源。颜色、高亮、下划线和评论定位以安全内嵌 HTML 保留；复杂表格保留 HTML 结构。「导出 Markdown」仅导出当前正文，「备份全部」导出包含全部定稿及评论的 JSON，可通过导入完整恢复；错误与冲突恢复入口同样下载完整集合备份。
- 支持旧模板的 HTML 经历标题和日期；私有字体图标转换为普通文字。支持 HTTP / HTTPS 图片链接、站内 Book / Mind / 定稿链接，以及编辑工具栏插入链接和图片。拒绝本地、data、脚本协议图片和含账号密码的图片链接；暂不支持图片文件上传。
- 「打印 / PDF」使用当前 Markdown 快照，生成独立 A4 打印预览，用户选择另存为 PDF；不包含评论、导航或其他定稿。跟随 Aa 字体风格，等待字体和图片加载，失败明确提示。PDF 不作为第二份在线内容维护。
- 导入指定本地文件不会修改原文件，也不会持续监听原文件。原始个人内容只通过登录后的导入进入数据库，不内置到源码、静态产物或其他账号模板。
- 沿用简洁纸张排版和全站明暗主题，390px 工具栏换行。正文使用全站 `.prose` 排版链路，Aa 影响编辑和预览；字号与行距使用共享阅读变量。定稿页隐藏会遮挡正文的看板娘与返回顶部按钮，保留账号和同步悬浮球。

## 存储与同步

- `GET /api/v1/resume`：从会话确定用户，返回本人简历快照。
- `PUT /api/v1/resume`：`expectedUserId`、`baseRevision`、`mutationId`、`state: { version: 2, documents: [{ id, title, content: { version: 1, markdown, comments? } }] }`。兼容旧单篇 v1 快照、带 `kind` 的旧集合快照和旧本机待发送回执；旧分类字段仅做兼容读取，新建与复制不生成该字段。沿用迁移 019，无需新增迁移。
- 每个账号的集合是一个事务快照，所有定稿共用云端 revision；多设备同时修改不同定稿也会触发版本冲突，保留完整本机集合等待明确处理。升级后拒绝旧单篇客户端覆盖集合；升级前已保存的旧回执仍可安全重放。
- `expectedUserId` 仅防止跨标签页切换账号后的旧草稿误写；授权始终使用服务器会话身份。响应 `no-store`，非安全请求精确校验 Origin，不接受用户查询参数。
- 迁移 `019_resumes.sql` 创建 `resumes` 与 `resume_mutations`。账号行锁、版本检查和同一数据库事务保护并发更新；稳定回执支持网络失败后的幂等重试。
- 输入停止 800ms 后自动保存，连续输入最长 4 秒触发保存；同时只发起一个写请求。正文与评论作为一个快照原子提交，只修改评论和保存中再次修改评论也会进入下一轮保存。失败最多自动重试三次，仍可手动重试或下载草稿。
- 未确认保存的草稿按账号写入本机存储，保存成功移除；恢复后先核对版本。冲突保留本机草稿，不覆盖新云端版本，可下载草稿后明确读取云端。
- 账号变化或失效清除内存、待发请求及当前账号恢复草稿；普通刷新或导航保留未保存草稿。迟到响应不能恢复旧账号正文。手动刷新过程中发生的新编辑也不会被覆盖。
- 文档展示和粘贴均经 DOMPurify 白名单处理，禁止脚本、iframe、事件属性、危险链接与布局 CSS。
- 批注标记只允许 `span[data-resume-comments]` 中有效的 UUID，粘贴清除复制的批注定位，避免误关联旧评论。前后端均校验评论字段、数量、长度、唯一 ID 与时间格式。

### Go 代码预览与选中文字高亮

- 编辑和预览支持 fenced Go 代码语法着色，也支持 lowlight 常用语言；未指定或无法识别语言时保留可读的纯代码。代码块底色固定白色，明暗主题均使用适合白底的语法颜色；代码字体跟随 Aa。
- 高亮与普通正文使用同一个操作：在「文档编辑」选中代码文字，右键「高亮」，或点击现有工具栏「高亮」。支持局部文字、整行和跨行选区，选中多少文字就高亮多少文字；不提供行号高亮或行数配置入口。「预览」只读展示已保存的高亮。
- 没有手工标记的代码仍导出 fenced Markdown，并保留语言与围栏说明。带局部高亮或颜色的代码使用安全内嵌 `<pre><code>` HTML 保存，因为 fenced Markdown 无法表示文字选区标记；代码源文本保留空行、尾部换行、缩进、反引号、HTML 字符及私有区字符，语法着色不会写入源码。
- 代码高亮、颜色和编辑均支持撤销重做；文字标记随正文编辑移动，自动保存与刷新后保留。清除最后一处标记后可继续导出普通 fenced Markdown；只读打开、切换预览或切换 Aa 不改写正文。普通正文评论定位保持不变，代码块仍不支持文字评论。
- 长行在代码块内部横向滚动，390px 页面无横向溢出；默认排版的深色正文与一级标题使用可读颜色。「文档编辑」工具栏可插入 Go 代码块。

- 超过 5 万字符的单个代码块使用纯代码，避免同步着色阻塞编辑；仍保留手工文字高亮。导入继续经过 DOMPurify 白名单，语法渲染使用安全节点装饰，拒绝任意 class、脚本、事件和布局 CSS。
