# 沉沦之海

- `/ocean` 是 Pages / cloud 共享的全屏海洋体验，导航位于 Planner 与关于之间，移动端同步出现在「更多」栏目。
- 通过独立路由渲染，不挂载博客 Layout，提供「返回海岸」回到首页；本页暂不显示 Cookie 提示，返回博客后沿用原提示语义。
- 自动下沉约 72 秒，叙事深度 0–1200m；海面折射、光束、悬浮物、气泡、鱼群、鲸、水母随深度变化。数字为场景刻度，不是潜水指导。
- 支持暂停、重新入海、鼠标视差、滚轮与深度滑块；Canvas 最多 30fps，DPR 上限 1.75，窄屏减少粒子，后台停止动画，卸载清理事件与 rAF。
- 遵守系统减少动效偏好：静态画面与手动深度探索。Canvas 不可用时保留渐变与操作，显示降级说明。
- 环境音默认关闭，点击后使用 Web Audio 合成低通噪声；暂停时淡出，离页关闭 AudioContext；加载失败显示提示。
- 页面使用统一 Seo，已登记 SSG、sitemap、llms.txt 与站内链接校验。
