# 文章回看 V2

2026-11-07，本地实现，尚未发布。

V2 是 cloud 构建专属的独立懒加载路由 `/articles-v2`。登录后从云端账号面板进入；原 `/articles`、`PostCard` 和 `/post/:id` 行为保持原样。V2 直接复用横向卡片，展示已有封面、标签、摘要和分享入口；点击标题或封面进入原文章详情，不增加个人阅读次数。

页面与原文章列表采用相同宽度和移动端边距。没有可见的一、二级介绍标题、整页底色外框或概况面板；保留仅供辅助阅读的 h1。每篇文章下面直接展示分类、最近阅读、次数与记录/撤销按钮，操作行没有独立背景或边框。

## 交互

- 阅读分类只有「想看、已看、暂不看」。没有已保存分类的文章默认想看；默认展示全部文章，可切换到其中一类。
- 手动改变分类不增加或清空阅读次数；标为已看也可以保持 0 次。
- 主动记录后自动归入已看。北京时间同一文章每天最多一次，可撤销并再次记录；撤销保留历史，重新计算次数和最近阅读。
- 撤销最近一条有效记录时，如果分类仍是已看，则恢复记录前分类；手动改为想看/暂不看后撤销不会覆盖分类。撤销更早的历史不改变较新阅读的分类。
- 不提供定期回看、到期清单或回看间隔。旧 `queue` / `review` 查询链接按全部文章显示。
- 默认次数少的在前，也可按次数多、最新发布排序；支持标题/标签/摘要多关键词过滤、分类筛选与每页 9 篇。筛选与分页保留在 URL。
- 阅读记录弹层展示最近 20 条，同一天的新记录排在已撤销记录之前，支持撤销历史记录；正文阅读的本机进度与个人主动计数独立。

## 登录和保存

真实会话 Cookie 授权，只要求登录，不要求绑定 GitHub。未登录不请求个人记录、不展示管理控件；账号切换、退出和卸载使旧请求失效。没有私人 localStorage 副本。

`GET/PUT /api/v1/articles/reading` 使用账号私有快照。新增迁移 `013_article_reading.sql`，包含 `article_reading` 与幂等回执表。服务端使用用户行事务锁、revision 比较和 mutation ID；回执对 JSONB 标准化后的摘要做比较，较早成功请求重放也不会覆盖较新内容。请求失败提示尚未确认保存，手动重试保留原 mutation ID；冲突提示读取云端版本后重新操作。

API 同源、精确 Origin 检查，响应 no-store；JSON 校验字段、日期、容量、关联文章和同日重复记录。静态 V2 入口只有加载壳与 noindex 元数据，不包含私人数据，不进入公共 sitemap。Pages 不生成入口或加载 V2 代码。

当前快照为 `version: 2`，分类只保存 `postId` 和 `interest: want | seen | skip`；新增事件可包含 `previousInterest` 以便撤销。前端仍严格读取旧 version 1：暂不看保留，其余有有效阅读记录的转已看，没有有效记录的转想看，丢弃计划字段。revision、全部阅读事件和撤销标记保留；下一次主动保存写入 version 2。后端兼容两种严格契约，沿用同一 SQL 表，不清空或重建数据。
