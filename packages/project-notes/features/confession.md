## 当前版本：体积雾与原教堂 Galgame（0.7.10）

移除教堂全部植物；墓地采用 WebGL 40 步三维噪声密度射线积分，风驱动流动、低位浓度与随机慢变化，独立物件 Alpha 高度代理用于遮挡，非 mesh 深度缓冲。画布边缘柔化、冷青夜色与门光融合。

凛在中轴通道随机目标间移动/停留，暂停、后台、弹层与减少动态效果冻结且保留位置。点击后原教堂保持可见，近景透明立绘与底部 Galgame 对白框叠加；逐字文字、固定中文配音、回听/静音/结束。当前待机为代码呼吸/摇摆，步行为站姿精灵位移加小幅摆动，不是 Cubism、口型或新骨骼模型。

六句原创成年女性合成语音为工程本地 WAV，已取得源音转写并修正实际切片对应；不模仿原作声优、不朗读或外发私密记事。原明确归档、失败保留、账号隔离与独立阅读保持。39 项功能目录定向与全前端 180 文件 1447 项回归通过，双构建通过；实际声音听感与 GPU 渲染不由单测替代。详见 `../versions/0.7.10.md`，未推送/上线。
