# 关键词搜索与 Road 移除

日期：2026-10-23。

搜索页 `/search` 提供常用关键词，按公开文章的标签与分类统计，每篇文章对同一个词只计一次。
点击关键词直接检索并更新 `q`，保留已有 `scope`；查询、清除、范围切换与直访 URL 继续复用现有同步逻辑。

关键词支持空格、逗号（含全角）、顿号和分号分隔，去重后要求全部词命中。
排序仍由文章数据层的字段权重与日期决定，搜索索引按需加载，保留结果缓存、防抖和迟到请求守卫。
桌面与移动端复用文章卡片，搜索结果展示标题、分类、摘要、正文或标签的命中片段，
通过安全文本节点高亮关键词，保留大小写、全角字符与原文。其他页面的普通卡片保持原有展示。

按用户要求删除 Road 页面、画布、布局与弹层代码、数据服务、专用测试及两份配置；
移除桌面和移动端导航、路由预加载、样式、SSG 页面、sitemap、llms.txt 与内容校验的路由声明。
旧 `/road` 路径落入现有 404 页面，输出 noindex。历史版本记录与文章内容不参与功能清理。
无新依赖，无 API 或数据库迁移。

验证：

- 类型检查通过，ESLint 0 错误，仅 4 条既有 Fast Refresh 警告。
- 131 个测试文件、1041 项前端与脚本测试通过；相关首轮 100 项通过。
- 全量测试使用本机 Python 3.13 和 2 个 worker：系统 Python 不支持部署解包的 `filter` 参数，
  默认高并发会使上传脚本测试超过既有 5 秒限制。测试与生产部署脚本未为此修改。
- Go 1.27.3 服务端 `go test -race -count=1` 通过；未配置 `TEST_DATABASE_URL` 的 PostgreSQL 集成用例跳过。
- Pages 和 cloud 完整构建、SSG、SEO 与部署隔离审计通过；生成源码和产物未保留 Road 路由或模块。
- 真实浏览器验证常用关键词点击、命中片段与高亮、多关键词正文检索、带 `q/scope` 直访恢复、
  桌面导航清理及 `/road` 的 404/noindex 行为。移动卡片的片段与高亮由组件测试验证。
