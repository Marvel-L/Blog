# Mind V1

实现日期：2026-11-15。代码与本地验证完成；尚未部署线上。

## 入口与交互

- 导航新增 Mind。cloud 使用同源 `/mind`；Pages 跳转 `https://43.138.216.53/Blog/mind`，不打包 Mind 编辑器或发起其账号 API。
- 匿名显示账号登录/注册入口。列表、创建、读取、保存均由服务端会话鉴权，数据按账号隔离。
- 默认 dashboard：导图列表按更新时间排序，可按名称搜索，点击 `+` 创建思维导图或逻辑图。
- 导图编辑器通过 `/mind?id=<uuid>` 定位；标题可编辑，两种布局随时切换，保留同一节点树。
- 思维导图两侧展开；逻辑图向右展开。节点自动排布并绘制连接线。
- 不同分支的同深度节点不按统一列对齐；子框从自身父框的外沿展开，短分支不受其他长分支宽度影响。逻辑图父子横向留白为 40px，思维导图继续使用 64px。
- 选中节点后：Enter 创建同级，Tab 创建子主题，Delete/Backspace 删除整个分支；根节点不可删除，根节点 Enter 创建一级主题。
- 双击/F2/空格编辑，Shift+Enter 换行，Escape 完成编辑。输入框中的 Delete 保持文本删除语义，中文输入法确认不创建额外节点。
- 支持撤销/重做、方向键选中节点、✅❌⭐💡🔥❓🎯🚀 标记和清除。
- 表情在节点文字前同行显示；节点宽度由实际字体和最长一行确定，只有手动换行才增加行数，节点尺寸可以不同。
- 输入时固定编辑框起点和周边节点位置，文字左对齐，编辑框按内容扩展；完成编辑后按最终尺寸排布。各分支顶部固定、宽度只影响自身后代；在末尾追加节点不移动前序主题，增加高度仅让需要腾出空间的后序分支顺延，避免全图居中和整列宽度变化引发大范围位移。
- 节点与连线复用未变化的布局对象并跳过重复渲染；只渲染视野附近的节点和连接线，保留正在编辑的输入框，平移/缩放时显示相应分支。完整树、布局、方向键导航、拖动判断和自动保存仍覆盖全部节点。
- 字体测量在绘制前完成；复用同一隐藏测量元素，缓存各节点尺寸和文本行，只测量变化的文字，尺寸相同不触发二次更新。字体/主题切换重新测量，避免逐字输入时反复跳动和光标滚动。
- 工具栏提供六种节点颜色、自定义颜色和恢复自动配色；选择的颜色按节点保存。
- 拖动节点到目标上方/下方调整同级顺序；中央/后侧作为目标的子主题。整条分支一起移动，保留文字、颜色、标记、子主题，支持撤销重做。
- 拖动时显示放置提示；禁止移动根节点、拖进自身/后代或超过 32 层。思维导图跨侧移动同步分支方向，手机支持触屏拖动。
- 空白区域拖动、触控板双指滚动平移；双指捏合缩放。包含 Chromium Ctrl-wheel、Safari gesture 事件和触屏双指路径。工具栏提供缩放、100%、适应画布。
- 保存画布中心的世界坐标与缩放比例，避免不同屏幕大小改变坐标含义。
- 编辑器右上角提供全屏切换；全屏内保留标题、结构选择、节点编辑、拖动、配色、快捷键、缩放和自动保存。退出按钮与 Esc 可返回普通编辑器。
- 全屏展开到浏览器页面的整个内容区，保留浏览器地址栏与标签页；切换时保留同一画布 DOM、选中节点、输入、撤销历史和世界坐标视角，手机与深色主题均支持。
- 窗口全屏隔离后台交互、限制焦点在编辑器内；退出或离开导图时恢复页面滚动和后台交互，不把编辑器注册为会禁用节点快捷键的普通弹层。

## 保存与接口

- 编辑后 600ms 防抖自动保存；持续输入最长约 3 秒提交一次。单导图串行写入，保存中仍能继续编辑。
- `/api/v1/mind/maps` 返回账号私有摘要列表；`GET/PUT /api/v1/mind/maps/{id}` 读取或保存完整导图。
- 写入携带 `baseRevision` 与 `mutationId`；SQL 事务保存内容、递增版本与幂等回执。并发旧版本返回 409，不覆盖已保存的新版本。
- 本机恢复草稿与账号绑定；网络错误保留同一 mutation 重试，自动重试最多 3 次，也可手动重试。账号退出或切换时清理该账号草稿。
- 冲突时保留当前编辑，提供另存副本或显式加载云端版本。尚未保存时离开页面会提醒。
- 每图最多 1000 个节点、32 层，每节点 200 字；接口对树结构、唯一根、引用关系、数值范围、标记白名单做校验。
- 节点可选 `color` 使用六位十六进制颜色；旧节点没有此字段时使用自动配色。继续使用现有 JSON 存储与版本冲突保护。

- 单测覆盖树结构、布局无重叠、缩放锚点、快捷键、IME、撤销、权限、自动保存竞态、草稿恢复、账号清理、冲突处理。
- 真实 PostgreSQL 验证会话权限、账号隔离、保存及视角持久化、重放幂等、并发冲突、事务回滚与故障响应。
- 浏览器验证真实账号创建导图、编辑及刷新恢复；1440px 桌面与 390px 手机、明暗主题、无水平溢出、同步按钮无遮挡。
- 500/990 节点导图在最后一个主题后新增同级，再连续输入长文本：所有旧节点的世界坐标不变，浏览器可见节点在新增、输入和完成编辑阶段的位置偏移均为 0；完整节点树和文字保存、刷新恢复通过。990 节点的输入到下一帧中位耗时从 96.9ms 降至 11.1ms，P95 从 195.8ms 降至 17.8ms（本机 Chromium 开发模式，特定样例，不代表所有设备/树形）。
- Chromium pinch 路径通过浏览器滚轮事件验证；Safari 专属 gesture 代码尚未在 Safari 实机验证。
- 配套修正构建阻塞：文章《多实例单 IP 限流》的引用使用已有文章固定 ID；部署审计识别 Vite 导出的纯 Markdown 字符串，避免文章 API 示例误报，仍拒绝带调用或模板插值的可执行模块。
