# Mind V1

实现日期：2026-11-15。代码与本地验证完成；尚未部署线上。

## 入口与交互

- 导航新增 Mind。cloud 使用同源 `/mind`；Pages 跳转 `https://43.138.216.53/Blog/mind`，不打包 Mind 编辑器或发起其账号 API。
- 匿名显示账号登录/注册入口。列表、创建、读取、保存均由服务端会话鉴权，数据按账号隔离。
- 默认 dashboard：导图列表按更新时间排序，可按名称搜索，点击 `+` 创建思维导图或逻辑图。
- 导图编辑器通过 `/mind?id=<uuid>` 定位；标题可编辑，两种布局随时切换，保留同一节点树。
- 思维导图两侧展开；逻辑图向右展开。子树围绕父节点垂直居中，形成弧线分叉的“{”结构；左右分支分别计算高度，中心主题固定在世界坐标 `(0, 0)`。
- 不同分支的同深度节点不按统一列对齐；子框从自身父框的外沿展开，短分支不受其他长分支宽度影响。逻辑图父子横向留白为 40px，思维导图继续使用 64px。
- 选中节点后：Enter 创建同级，Tab 创建子主题，Delete/Backspace 删除整个分支；根节点不可删除，根节点 Enter 创建一级主题。
- 双击/F2/空格编辑，Shift+Enter 换行，Escape 完成编辑。输入框中的 Delete 保持文本删除语义，中文输入法确认不创建额外节点。
- 支持撤销/重做、方向键选中节点、✅❌⭐💡🔥❓🎯🚀 标记和清除。
- 表情在节点文字前同行显示；节点宽度由实际字体和最长一行确定，只有手动换行才增加行数，节点尺寸可以不同。
- 输入时固定编辑框起点和周边节点位置，文字左对齐，编辑框按内容扩展；完成编辑或新增、删除、移动、折叠后按各子树的最终高度重新居中排布，保持分支无重叠。宽度只影响自身后代，不统一对齐其他分支。
- 节点与连线复用未变化的布局对象并跳过重复渲染；只渲染视野附近的节点和连接线，保留正在编辑的输入框，平移/缩放时显示相应分支。布局、方向键导航、拖动目标和适应画布只处理展开的主题，保存和导出仍包含完整树。
- 字体测量在绘制前完成；复用同一隐藏测量元素，缓存各节点尺寸和文本行，只测量变化的文字，尺寸相同不触发二次更新。字体/主题切换重新测量，避免逐字输入时反复跳动和光标滚动。
- 工具栏提供六种节点颜色、自定义颜色和恢复自动配色；选择的颜色按节点保存。
- 拖动节点到目标上方/下方调整同级顺序；中央/后侧作为目标的子主题。整条分支一起移动，保留文字、颜色、标记、子主题，支持撤销重做。
- 拖动时显示放置提示；禁止移动根节点、拖进自身/后代或超过 32 层。思维导图跨侧移动同步分支方向，手机支持触屏拖动。
- 空白区域拖动、触控板双指滚动平移；双指捏合缩放。包含 Chromium Ctrl-wheel、Safari gesture 事件和触屏双指路径。工具栏提供缩放、100%、适应画布。
- 保存画布中心的世界坐标与缩放比例，避免不同屏幕大小改变坐标含义。
- 编辑器右上角提供全屏切换；全屏内保留标题、结构选择、节点编辑、拖动、配色、快捷键、缩放和自动保存。退出按钮与 Esc 可返回普通编辑器。
- 全屏展开到浏览器页面的整个内容区，保留浏览器地址栏与标签页；切换时保留同一画布 DOM、选中节点、输入、撤销历史和世界坐标视角，手机与深色主题均支持。
- 窗口全屏隔离后台交互、限制焦点在编辑器内；退出或离开导图时恢复页面滚动和后台交互，不把编辑器注册为会禁用节点快捷键的普通弹层。

## 保存与接口

- 编辑后 600ms 防抖自动保存；持续输入最长约 3 秒提交一次。单导图串行写入，保存中仍能继续编辑。
- `/api/v1/mind/maps` 返回账号私有摘要列表；`GET/PUT /api/v1/mind/maps/{id}` 读取或保存完整导图。
- 写入携带 `baseRevision` 与 `mutationId`；SQL 事务保存内容、递增版本与幂等回执。并发旧版本返回 409，不覆盖已保存的新版本。
- 本机恢复草稿与账号绑定；网络错误保留同一 mutation 重试，自动重试最多 3 次，也可手动重试。账号退出或切换时清理该账号草稿。
- 冲突时保留当前编辑，提供另存副本或显式加载云端版本。尚未保存时离开页面会提醒。
- 每图最多 1000 个节点、32 层，每节点 200 字；接口对树结构、唯一根、引用关系、数值范围、标记白名单做校验。
- 节点可选 `color` 使用六位十六进制颜色，可选 `collapsed` 为布尔值；省略时使用自动配色并展开分支。继续使用现有 JSON 存储与版本冲突保护。

## 导图文件与源码（2026-11-18）

已实现本地，尚未发布。本轮预览：`http://127.0.0.1:3004/mind`。

- 列表「导入文件」支持上传 `.json`、`.md`、`.markdown`，或直接粘贴源码；导入为当前登录账号的新导图，保留原标题。
- 编辑器右上角 `</>`「导图文件与源码」支持完整 JSON / Markdown 大纲下载、读取文件、源码编辑、校验、应用到当前导图。
- JSON 是推荐的主存储与版本管理格式，与现有 `MindState` / API JSON 结构一致，完整保留文字、层级、节点顺序、节点 ID、标记、手动颜色、折叠状态、布局和视角。导出不包含账号、导图数据库 ID、版本回执或认证信息。
- Markdown 适合编辑文本大纲；保留完整文字、父子层级与同级顺序，包括被折叠的子主题。导入时生成新的节点 ID，使用默认思维导图布局、自动配色、默认视角、全部展开，不保留独立标记字段。需要保留完整视觉状态时使用 JSON。
- 在线源码是独立草稿，点击「应用」且校验通过后才替换导图，随后沿用自动保存。整体替换作为一次可撤销操作，撤销/重做同时恢复该次替换的布局与视角。
- 源码有未应用修改时，关闭、切换格式或读取另一文件会提醒；刷新/关闭标签页也有未应用提示。读取失败、校验失败、保存创建失败均保留源码。打开后当前导图若已发生变化，会阻止应用以免覆盖新修改。
- 文件最多 2 MiB，继续遵守标题 120 字、节点 200 字、最多 1000 个节点与 32 层限制。JSON 不接受 schema 之外的字段，不执行导入文字中的 HTML 或代码。
- 导入创建沿用账号隔离、版本与幂等回执机制，失败重试保持同一导图 ID、mutation 与正文；账号切换后忽略旧请求与文件读取结果。
- 弹层普通模式挂载到 body，避免导航、账号悬浮球和 Cookie 提示遮挡；全屏时挂载到现有编辑器 host 内，避免被后台隔离机制设为 inert。手机、明暗主题均支持。
- 外部 Coding 工作流：导出 JSON → 在代码编辑器/AI 中修改文件 → 上传导入新导图，或在当前导图读取文件并应用。也可直接在源码编辑器修改。当前不监听本地文件变化，也不直接写入外部磁盘文件。
- 使用现有后端接口与 JSON 存储，无新增迁移；发布此扩展需更新 cloud 前端，Pages 保持跳转云端且不打包 Mind 编辑器。

### JSON 字段约定

顶层字段：`version: 1`、非空 `title`、`layout: "mind" | "logic"`、`nodes`、`viewport`。每个节点包含 `id`（小写 UUID）、`parentId`（父节点 UUID，唯一根为 null）、`text`、`emoji`（空字符串或现有标记白名单）、`side: -1 | 1`，可选 `color: "#RRGGBB"`、`collapsed: true | false`。`collapsed: true` 隐藏其后代，节点本身仍可见；不删除后代，也不清除嵌套节点的折叠状态。视角包含 `x`、`y`（中心世界坐标，绝对值不超过 1,000,000）、`zoom`（0.15–3）。

修改文字时保留 `id`；新增节点生成新的 UUID 并正确指定 `parentId`；删除节点时同时删除子树或重设子节点的父引用。结构必须为无环、连通的单根树。

### Markdown 大纲约定

```markdown
# 项目计划

- 中心主题
  - 设计
    - 页面<br />接口
  - 实现
```

标题行可省略，此时使用首个主题的文字作为标题。主题使用 `- `、`* ` 或 `+ ` 开头，每层缩进两个空格。只有一个顶层主题时它是根；多个顶层主题时自动增加以标题命名的根。空主题可写为 `- `。不支持正文段落、代码围栏或多级标题代替列表，格式错误会明确指出行号，不静默丢弃内容。

导出将节点换行写为 `<br />`，对 Markdown 标点加反斜线、对 `&<>` 与制表符/回车/首尾空格编码；导入只解码此约定，因此代码、HTML 字面文字、空行和首尾空格可还原为节点纯文本。

## 居中布局与分支折叠（2026-11-18）

- 层级视觉参考 XMind：深色中心主题、浅色一级分支、轻量下划线子主题，弧线连接；支持深色模式与节点自定义颜色。
- 有子主题的节点末端显示独立的圆形 `−` / `+` 按钮，分别收起或展开子分支；左分支按钮位于左侧，逻辑图始终位于右侧。缩小视图时按钮反向放大，最多 3 倍，保留可点击范围。叶节点没有无效按钮。
- 折叠状态自动保存，刷新后恢复；折叠只隐藏后代，主题总数包含隐藏内容，并显示已折叠数量。
- 支持嵌套折叠、撤销/重做；如果选中节点被隐藏，选择移到最近可见祖先。键盘 `−` 收起、`+`（或 `=`）展开选中分支，方向键跳过隐藏节点。
- 在折叠节点下新增或拖入主题会展开该父分支，方便继续编辑。折叠操作结束输入或拖动，避免隐藏节点残留输入框。
- `version` 保持 1，无新增数据库迁移。发布此轮需要同时更新后端可选 `collapsed` 校验和 cloud 前端；旧后端会拒绝带该字段的保存。已有 Mind 表仍需此前的迁移 018。
- 验证包括 54 项 Mind 测试、全量 1590 项前端测试与覆盖率门禁、真实 PostgreSQL 全量后端测试。Chromium 验证 19 节点的双侧/逻辑居中无重叠、嵌套折叠及刷新恢复、完整导出、撤销重做、固定输入起点、拖入折叠分支；390px 触屏、明暗主题和全屏检查通过，缩小视图下折叠按钮点击范围约 24px。cloud / Pages 构建与产物隔离审计通过。
