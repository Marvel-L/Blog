# 独立首页与横向文章列表

- `/` 是独立首页，顶部 Blog 品牌链接返回这里。当前沿用站点标题、副标题、描述和诗词封面；移除继续阅读和「浏览文章」引导，后续首页内容集中在 `pages/Home.tsx` 扩展。
- `/articles` 是独立文章列表。桌面导航和移动底部栏的「文章」入口均指向这里，文章详情页也保持该入口高亮。
- 文章页移除继续阅读、可见大小标题和说明文字，保留返回首页入口；辅助阅读标题隐藏显示，正文从分类筛选与搜索开始。
- 每篇文章占一行：左侧标题、摘要和标签，右侧可选小封面；底部展示日期、阅读时长、可选评论数及分享。没有封面时不显示占位图。浅色、深色和移动端使用同一套组件。
- `PostCard` 的 `layout="row"` 提供横向展示，既有搜索页保留默认卡片布局。文章分级仍复用 `RankFlash`。
- 每页固定 9 篇，精选和置顶文章保持现有排序优先级，每篇只占一个分页名额。分类、搜索、排序及页码继续与 URL 同步，越界页码自动修正。
- 旧首页 `q/category/sort/page` 查询地址在水合后跳转到 `/articles`，保留原参数。详情页「返回文章」和分类面包屑直接指向新列表地址。
- `useArticlePosts` 为文章页同步首帧数据、解锁后的文章刷新及失败重试；首页不再加载文章数据。移除继续阅读展示不清除已有阅读进度。
- SSG、页面 sitemap 和 `llms.txt` 已注册 `/articles`，首页不再预加载文章封面。
