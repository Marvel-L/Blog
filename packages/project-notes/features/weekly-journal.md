## 账号与保存

- 登录后才能读取和编辑周记，复用系统账号密码与 GitHub OAuth；每个账号只能访问自己的记录。
- `GET /api/v1/weekly-journal` 默认当前周；`GET/PUT /api/v1/weekly-journal?week=YYYY-MM-DD` 访问所选周。
- 身份完全来自服务端会话，拒绝客户端授权身份字段；新客户端发送 `expectedUserId` 作为账号切换校验，服务端发现会话账号不一致即拒绝写入，旧客户端请求仍兼容；非安全方法沿用精确 Origin 校验，响应 `no-store`。
- `017_weekly_journal.sql` 创建按账号和周一起始日期组织的快照及幂等回执；修订版本避免并发覆盖，快照和回执在同一事务提交。
- `weekly-journal/sync.ts` 按账号、周次维护保存会话：停笔 800ms 自动写入，持续输入最多每 4 秒触发保存；写入期间可继续编辑。失败后最多自动重试三次，复用原 mutation 回执，再提交之后的新输入。支持 Cmd/Ctrl+S、切周前保存、页面进入后台时尝试同步、联网后重试。
- 冲突后停止自动写入，保留本机编辑字段，合入其他日期及未编辑字段的云端新内容。用户核对后选择「使用当前版本」，或下载备份后读取云端版本。未提交留言阻止切周和切换日卡片；版本冲突需处理后再切周。页面和同步面板均不提供常规手动保存按钮，右下角同步球保留状态、刷新云端和本周 JSON 备份；仅失败时显示「重试同步」，冲突时显示版本处理入口。
- 未保存正文和已提交留言使用 `dblog-journal-v1:<user>:<week>` 本机恢复草稿，刷新后恢复。成功保存后删除草稿；账号退出或切换会清理该账号各周草稿、正文、输入和挂起请求，迟到响应不能恢复旧账号记录。未提交的留言编辑框仍需明确提交。
- 私密内容不进入 SSG、站点搜索或分享元数据。cloud SSG 生成独立入口和 `noindex` 元数据，首帧仅加载提示，不调用账号 API。Pages 构建不包含周记组件或同源账号 API，导航入口跳到云端站点。
- GitHub 登录回跳地址新增两个精确白名单：`/Blog/weekly-journal`、`/weekly-journal`。
