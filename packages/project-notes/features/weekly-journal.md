## 账号与保存

- 登录后才能读取和编辑周记，复用系统账号密码与 GitHub OAuth；每个账号只能访问自己的记录。
- `GET /api/v1/weekly-journal` 默认当前周；`GET/PUT /api/v1/weekly-journal?week=YYYY-MM-DD` 访问所选周。
- 身份完全来自服务端会话，拒绝客户端身份字段；非安全方法沿用精确 Origin 校验，响应 `no-store`。
- `017_weekly_journal.sql` 创建按账号和周一起始日期组织的快照及幂等回执；修订版本避免并发覆盖，快照和回执在同一事务提交。
- 保存失败保留输入；冲突后加载最新记录并保留编辑草稿，用户核对后可重新保存。账号变化清空正文、输入和挂起请求，迟到响应不能恢复旧账号记录。
- 私密内容仅保存在数据库和当前页面内存，不进入浏览器持久存储、SSG、站点搜索或分享元数据。cloud SSG 生成独立入口和 `noindex` 元数据，首帧仅加载提示，不调用账号 API。Pages 构建不包含周记组件或同源账号 API，导航入口跳到云端站点。
- GitHub 登录回跳地址新增两个精确白名单：`/Blog/weekly-journal`、`/weekly-journal`。
