# 天空背景外观

日期：2026-11-07。

## 实现

- 导航栏的「外观与氛围」菜单在浅色、深色选项下新增「天空背景」开关；开启后按钮显示已开启，导航入口使用云朵图标并播报当前天空背景。
- 天空与明暗配色独立，可搭配浅色天空或深色夜空；可继续叠加小雨、樱花、鲸鱼等既有氛围组合，不占用两个特效名额。
- `useBackgroundAppearance` 持有全站背景选择。使用独立的 `background-appearance` 存储 `default` / `sky`，保留 `localStorage.theme` 只存 `light` / `dark` 的契约。
- 首次渲染使用确定的默认值，挂载后恢复个人选择；仅显式操作写入存储。存储不可用时仍可切换当前会话，未知值按默认背景处理。
- 复用 `BookSky`，通过 `data-sky-background` 控制普通页面的全屏天空、导航材质与隔离层；`data-book-sky` 继续只控制书架页面的布局和默认天空。
- 普通页面之间导航及刷新保留选择，关闭后恢复普通背景。专注阅读和 Love 面使用各自背景，退出后恢复个人天空选择；书架始终保持既有默认天空。
- 手机外观面板对齐屏幕两侧，解决 320px 窗口下左侧溢出；面板高度按视口限制并支持滚动，桌面继续使用原有下拉位置。

## 验证

- 5 个相关文件 / 116 项测试通过，覆盖背景恢复与关闭、明暗组合、氛围组合保留、跨页面、专注阅读及 Love 面、存储失败、未知值和 SSR 确定性，以及原书架交互。
- 前端类型检查、改动文件 ESLint / Prettier 通过。
- Pages 完整构建、SSR / SSG、产物审计、SEO 与部署隔离通过；使用 `SKIP_IMAGE_COMPRESS=1`。
- 浏览器实际在归档页开启天空、切换深色并导航到文章列表，背景与选择保留。
- Chrome 在 320×568、390×844、1440×900 下验证开启浅色天空、切换深色、刷新恢复和关闭。手机菜单左右均保留 12px，三个尺寸的菜单均在视口内，页面无横向溢出；明暗过渡完成后的画面可读。
