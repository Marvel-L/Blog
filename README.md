# 欢迎来到我的世界

## 正文图片尺寸

```md
![说明](a.jpg)                    # 默认通栏
![说明](a.jpg){.small}            # 缩小居中（另有 {.medium}）
![a](a.jpg){.inline} ![b](b.jpg){.inline}   # 并排（默认 small）
![a](a.jpg){.small}{.inline}      # 多修饰：多个 {} 依次书写
![截图](x.jpg){.no-dark}          # 暗色不降亮（兼容 title "no-dark"）
```

详见 `ai-rules/post.md`。
