# 语言基础与阅读方式

学习 Go 时，不要只记“语法允许怎么写”，还要同时理解值的复制、变量的生命周期和接口背后的动态类型。

## 建议顺序

- 变量、切片与 map
- 函数参数与值传递
- 指针和方法集
- 接口与错误处理
- goroutine、channel 与 context

每一章只保留可复用的判断规则，具体踩坑放到关联文章里。
