# 整体思路

1. 设计一个 带有 容量大 桶

2. 给定速率 生成 可用令牌

3. 每次请求消耗对应的令牌，如果没有令牌 可用 则失败

# 细节

由于我们需要支持 ==进程级== 的限流，因此需要考虑 多 goroutine 的情况，所以需要增加一个 `mutex`

1. 其他参数 包含 速率、容量、当前令牌数量、最后填充时间

```go
type Limiter struct {
	mu         sync.Mutex
	interval   time.Duration
	burst      int
	tokens     int
	lastRefill time.Time
}
```

## 计算处理

1. 计算当前会补 多少个 令牌

```go
now := time.Now()
wholeTokens := now.Sub(l.lastRefill) / l.interval
```

1. 判断是否能把桶补满 如果已经满了 则直接赋值容量
2. 否则补充当前桶

```go
if wholeTokens >= time.Duration(l.burst-l.tokens) {
    l.tokens = l.burst
    l.lastRefill = now
}
```

3. 如果没有令牌 则返回错误 限制
