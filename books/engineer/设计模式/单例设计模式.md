单例设计模式 ==**仅**允许创建一个对象的设计模式== 通常对某些资源的访问

例如 :

1. 数据库连接
2. 线程池

# 懒汉式

特点是 ==首次使用时== 创建单例实例.

1. 通过使用 `sync.Once` 实现仅一次注册

```go
package singleton

import "sync"

var (
	instance *Singleton
	once     sync.Once
)

type Singleton struct {
}

func GetInstance() *Singleton {
	once.Do(func() {
		instance = &Singleton{}
	})

	return instance
}
```

# 饿汉式

饿汉式 是在 系统启动时就创建 对应的实例

```go
package singleton

var instance *Singleton = &Singleton{}

type Singleton struct {
}

func GetInstance() *Singleton {
	return instance
}
```
