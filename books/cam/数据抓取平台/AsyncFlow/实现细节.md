# 发起下载请求

## 发起演进

1. 一开始我们这个系统支持的是 单一发起 即 客户/产品 手动发起 。导致如果要发起 多账户的时候 比较困难

2. 后续为了支持 批量抓取，我们在 原有的状态基础上 即 `packaging_data` 之前增加了 `not_started` 的流程

任务先以 `not_start` 的形式入库, 然后通过 ==后台启动一个协程== 实时监听我们的消息消息内容

**问题:**

1. 为什么不适用 定时任务 而是 使用实时监听的形式 ？

2. 这里如果是多实例的情况下应该怎么办 ? 参考合同项目 只有主实例 跑这些内容 ？ 或者说就拆成定时任务 通过三方平台调度？

   - 常规做法 **通过Redis 租约锁, 抢主实例**

## 限流控制

1. 设计了一个 1分钟 一次的进程级 限流，防止单一进程 打爆 IP 权重限制

2. 使用 Redis 控制对应的月额度限制，每次发起打包任务之前判断是否有可用次数

**问题:**

1. 进程级的限流是怎么控制的 ？

   A : mutex + 令牌桶
   Q : mutex 会频繁加锁，是否有其他更好的办法 ？

   - CAS & Mutex

2. 如果一个 IP 在多个实例上 怎么办 ？

   A. 改成 Redis 控制限流，使用 Set ex 控制分钟级别的限流，注意的是 使用 lua 脚本, 查询和减少是一个原子性操作

## 任务入库

1. 成功请求交易所之后，我们会把交易所的 `download-id` 和 `download-path` 预先存入到 db 中

2. 然后将这些数据 `json` 化处理到我们的 `Redis-List` 中

**问题:**

1. 这里如果插入数据库失败了怎么办 ？

   - 首先我们这些操作都是人为操作，因此会考虑在系统升级前 稳定的时候进行操作
   - 因此失败的原因也只能是因为连接波动导致的，如果插入失败会发送对应的 Sentry , 然后人为的通过 Sentry 发送出来的信息 构建 DDL 用于插入

2. 插入 Redis 失败了怎么办 ？

   - Redis 插入失败的话 可以尝试立即重试，重试个 3次 左右
   - 或者是等我们后面补偿任务触发

# 请求打包阶段

## 任务轮询

任务轮询阶段 会根据 每个交易所注册的 handler 找到对应的 请求封装

我们会单独启动一个后台任务，轮训当前 Redis List 中有数据的内容，通过 `RPOP` 取出任务 和 `LPUSH` 放入任务

1. 请求任务，并且忽略限速、权限错误等报错 ，遇到这种错误仍然继续运行 直到 30天 结束

2. 如果请求到下载的URL, 那么解析对应的 URL 并且进行 下载

3. 下载之后保存到本地，并且把本地保存文件的地址 更新到 DB 和 MQ 中

**优化点**

1. 单独启动 3个 监听到 后台 goroutine , 通过 channel 来进行通信处理
2. 当我们准备好下载链接之后 会尝试将下载任务写入到 channel 中，如果写入不了则返回队列，等待下一次轮训

**问题:**

1. 不断的 `RPOP` 和 `LPUSH` 是否会有性能上的问题

   - 单元素 RPOP、LPUSH 是常数时间操作，复用 Redis Client 能避免反复创建连接，但不会消除每次命令的网络和执行开销。当前轮询有固定间隔，所以不能把队列任务多直接等同于 Redis 压力大；更需要关注的是任务扫描周期，以及同步下载对后续轮询的阻塞。

## 下载 & 存入本地

我们单独在本地机器上开辟了 一个 tmp/ 目录用于存放对应的数据

并且会在程序启动的时候 单独开启一个后台程序， 用于清理我们超过30天的文件，因为我们的限额是 30天 一次，因此文件只需要保持 30天

**问题:**

1. 为什么要存放到本地？ 不应该存放到 `oss` 或者是其他什么地方吗

   - 当前这条下载、导入链路没有接入对象存储，因此我们优先复用本地文件方案，==减少接入和运维成本==。

追问 :

==下载发生在 A 机器，消息被 B 机器消费，B 怎么读到这个文件？==

2. 下载的过程中如果中断了怎么办 ？

   - 如果下载过程中中断了，当前的任务会 download_fail 然后重新下载

   追问: 是否会继续接着进度下载？

   - 不会，能否断点下载取决于对手方接口，但是对手方接口不支持，因此是全量重下

# 数据入库阶段

## 分批入库

1. 用户的数据是一个大的 ZIP 文件，一个 ZIP 内会存在很多个 `file`

2. 我们按照文件顺序进行读取，使用 Redis 记录每个文件的处理进度

```go
func ConsumeCsvZipBatch(entry *common.ImportEntry, batchSize int, filePath string, handler CsvZipBatchHandler) error {
	defer func() {
		for _, trans := range entry.TransCache {
			// okx trans匹配失败的记录，加入异常日志
			if trans.Tags != nil {
				if _, err := db_internal.InsertDBErrorRecord(db_internal.DBErrorRecord{
					Account:      entry.Account,
					FetchMode:    string(ec.DataSourceAsync),
					RecordType:   string(ec.RecordTableTrans),
					ErrorTime:    time.Now(),
					ErrorMessage: "failed to pair up due to missing dual trans record",
					Original:     fmt.Sprintf("%v", trans),
				}); err != nil {
					cam.SentryWarn("failed to insert error record table", err.Error())
				}
			} // else: 是用于去重的合约记录，不需要记录异常
		}
	}()
	if !entry.NeedContinue {
		return nil
	}
	zipReader, err := zip.OpenReader(filePath)
	if err != nil {
		return err
	}
	defer zipReader.Close()
	if len(zipReader.File) == 0 {
		return nil // there is no file
	}
	sort.Slice(zipReader.File, func(i, j int) bool { // make sure we can read multiple csv with a particular order
		return zipReader.File[i].Name < zipReader.File[j].Name
	})
	for i, f := range zipReader.File {
		if i <= entry.CsvProgress-1 { // 进度恢复
			continue
		}
		fOpen, err := f.Open()
		if err != nil {
			return err
		}
		csvReader := csv.NewReader(fOpen)
		csvReader.LazyQuotes = true
		rawData := make([][]string, 0, batchSize)
		hasSkipFirst := false
		for {
			record, err := csvReader.Read()
			if err == io.EOF {
				asyn.Logger.Info(fmt.Sprintf("[ConsumeCsvZipBatch] finish the [%d] csv for zip [%s]", i, entry.FilePath))
				break
			}
			if err != nil {
				fOpen.Close()
				return err
			}
			if !hasSkipFirst { // skip title
				hasSkipFirst = true
				continue
			}
			if len(record) == 0 {
				continue
			}
			rawData = append(rawData, record)
			if len(rawData) == batchSize {
				if err := handler(entry, rawData); err != nil {
					fOpen.Close()
					return err
				}
				rawData = make([][]string, 0, batchSize)
			}
		}
		if len(rawData) > 0 {
			if err := handler(entry, rawData); err != nil {
				fOpen.Close()
				return err
			}
		}
		fOpen.Close()
		entry.CsvProgress++ // incr csvProgress
		if err := SetProgress(keyForKeepImportProgress, "entry", cam.JsonMarshal(entry)); err != nil {
			return err
		}
	}
	return DeleteProgress(keyForKeepImportProgress)
}
```
