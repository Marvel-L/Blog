# 需求背景

1. 我们账户录入进来之后 想要获取全量的数据，用于供给上层计算 ==近 3 年== 的数据

2. 实时接口请求的数据范围有限, 一般都是 3 个月左右. 因此只能通过 对手方提供的 ==异步下载流程进行处理==

从我们系统进行理解, 这一整个业务逻辑流程如下 :

1. 向交易所发起下载请求, 交易所进行数据打包, 打包时长由交易所那边决定 可能出现打包 2个月 的情况

2. 我们通过 下载 id 进行轮询, 获取打包进度。 数据打包完成之后, 会返回一个 URL_Link

3. 我们通过 URL_Link 进行下载, 获取数据
