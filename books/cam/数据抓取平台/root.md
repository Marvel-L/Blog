数据抓取平台

项目背景 : 保证新账户的历史数据完整性抓取 和 存量账户的 实时数据 以及 低延迟 抓取. 提供一个 不重不漏的 交易业务数据抓取

技术架构 : Postgres 做数据仓储和实时任务抓取记录, Goroutine Pool 结合 CronJob 实现分层抓取数据, Grafana 监控入库率, Websocket 处理低延时抓取

核心工作:

- **异步文件抓取**: 实现交易所历史文件的申请、状态轮询、下载解压与 CSV 导入，结合 PG 任务持久化和 Redis 文件级进度恢复，补充 REST 回溯窗口之外可导出的历史数据
- **常规抓取调度**: 基于常驻 Worker 池执行全历史与近期增量抓取，通过 Redis 保存轮次状态与执行进度，支持任务持续推进和中断恢复。
- **实时采集加速**: 接入 WebSocket 明细推送,并针对仅提供余额变动事件的业务,实现实时数据延迟最大2分钟 内入库
