# 能力雷达内容维护

当前 `config.json` 为 `{}`：没有任何等级数据。雷达只显示外框、维度名称及中心黑点；不会自动填 N，也不会发布 Demo 里的示例经历。

## 填写等级

在 `config.json` 中按需增加对应维度，例如：

```json
{
  "算法": "N",
  "语言广度": "G"
}
```

九个键：算法、语言广度、语言深度、业务的广度、业务的深度、技术的广度、技术的深度、AI、学历。

可选值：N / G / B / V / O / R。缺失、null 或空字符串表示尚未配置，无等级、不参与面积评分；其他非空非法值会报错并阻止构建。

## 添加说明

在本目录创建与维度同名的目录，例如 `算法/`，再自行编写 `Index.md`、`Stage1.md`、`Stage2.md` 等。Index 优先，其余自然排序；历史记录不强制等级递增，也不会自动修改当前等级。

Markdown 支持普通文章的 Aa 排版、双等号与三等号高亮、代码块、公式、Mermaid 和图片预览。相对 Markdown 文档链接可以使用 `Stage1.md`；相对图片可放在当前维度目录，构建时复制到静态资源目录。说明文件必须有正文，空文件会报错。`draft: true` 的 front matter 不发布。

修改内容后重新运行 `npm run gen:data` 或正常开发/构建命令；正式阅读路径为 `/about/ability/维度/文件名.md`，由路由自动进行 URL 编码。

能力文件不进入普通文章、搜索、RSS/Feed；公开正文生成独立 SSG 页面并加入页面 sitemap。所有放入本目录的非草稿说明均为公开内容，不要写入密钥或不准备公开的信息。
