# 力扣刷题记录油猴脚本

脚本文件：`leetcode_今昨日刷题记录获取.js`。无需服务器或额外 API key。

## 安装

1. 在浏览器安装 Tampermonkey（油猴）。
2. 打开油猴管理面板，选择「添加新脚本」。
3. 删除默认内容，复制脚本文件的全部内容进去，保存。
4. 打开或刷新 <https://leetcode.cn/u/marvel-l-1317/>，点击右下角「刷题记录」。

## 使用

输入任意力扣中国站的用户主页链接，也可以只输入用户名。脚本会优先使用当前用户主页的用户名，否则使用上次抓取的用户名。

选择「今天」「昨天」「前天」，或通过日期框自选日期，再点击「抓取记录」。日期按照中国时间 UTC+8 的 00:00 至次日 00:00 筛选，不受电脑时区影响。

结果按当天提交时间从早到晚排列，同一道题的重复提交合并。点击「复制 Markdown」或「下载 .md」。输出不附加序号、列表符号或日期标题，格式如下：

```markdown
[最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/)
[乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/)
```

这些行仅用于说明输出格式，实际内容以抓取结果为准。

## 记录范围

- **自动模式**：输入的主页属于当前登录账号时，分页读取本人历史；其他情况下读取该用户的公开最近通过记录。
- **公开模式**：任意用户均可查询，但力扣只提供有限的最近通过记录，日期较早或提交较多时可能遗漏。脚本会显示范围提示，不能将空结果理解为当天一定没有刷题。无效用户名与没有公开记录的用户可能都返回空列表。
- **本人历史**：需要先在当前浏览器登录对应的力扣账号。默认只包含通过提交；取消「只看通过的题目」后，包含当天所有判题结果。同一道题仍然只输出一次。

本人历史按每页 20 条读取，记录早于所选日期后停止。每页请求之间间隔 300 毫秒，最多读取 80 页；超过上限会显示「结果可能不完整」。可点击「取消」，收起悬浮窗也会取消正在进行的抓取。

脚本只向 `https://leetcode.cn` 的固定接口发送请求，利用网站当前登录状态；不会向第三方上传刷题记录。油猴本地设置只保存用户主页、来源选项和通过筛选，不保存提交历史或登录凭证。

## 验证与接口说明

2026-11-10 已验证公开查询路径为 `/graphql/noj-go/`，字段为 `recentACSubmissions(userSlug)`，能返回中文题名、题目 slug 和秒级提交时间。旧的 `/graphql/` 路径不提供该字段。

本人历史使用 `/api/submissions/`；未登录请求已确认返回 HTTP 401。由于开发验证环境没有登录该账号，本人分页流程通过测试数据验证，尚未完成真实账号历史请求验证。若力扣后续更改 `submissions_dump`、`title_slug`、`has_next` 等字段，脚本会报告格式错误。

遇到登录过期、网站验证、请求频繁或接口变化时，悬浮窗会显示原因；请先在力扣网站处理后再重新抓取。
